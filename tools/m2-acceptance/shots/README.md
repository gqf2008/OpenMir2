# tools/m2-acceptance/shots —— 真客户端验收截图目录（占位）

本目录是 **M2 验收②「真客户端可玩证据 = 7 张截图」** 的归档位置（`check_screenshots.ps1` 的默认 `-ShotsDir`）。
现在只有本说明（占位）；7 张图由验收人在真客户端阶段按 `../README.md` §2 逐张截下并命名。

7 个规定文件名（缺一即 `check_screenshots.ps1` 判红）：

| 文件 | 画面 |
| --- | --- |
| `m2-01-enter-map.png` | 进图后（人物站在地图里） |
| `m2-02-walk.png` | 走路中（位置已变） |
| `m2-03-talk.png` | 说话（聊天框出现本角色文本） |
| `m2-04-see-others.png` | 看见别人（屏内出现另一角色） |
| `m2-05-attack.png` | 打怪（攻击/怪物受击） |
| `m2-06-pickup.png` | 捡物（地上物品消失或背包出现） |
| `m2-07-relogin.png` | 小退再进不黑屏 |

> 大图建议归档到 `E:\tmp\m2-acceptance\<run>\shots\`；本目录只保留 `.gitkeep`/本说明或小图。
> 别把 GB 级截图直接入库。
