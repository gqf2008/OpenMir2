### 4.2 原始输出 + 路径 + hash

**hash 口径（评审 N-1）**：`SHA-256(文件字节，先把 CRLF 归一为 LF)` ==
`git show <commit>:<path> | sha256sum`（git blob 内容 hash）。核心.autocrlf=true ⇒ 工作树是 CRLF，
裸 `sha256sum` 会得另一个值。清单是唯一权威：

- 清单：`tests/parity/evidence/M4/evidence-hashes.json`
- 复核：`python -I tests/parity/M4/evidence_hashes.py` → `GREEN: 证据 hash 复核 N/N 项一致`

| 产物 | 路径 |
| --- | --- |
| ① 计数表 | `tests/parity/evidence/M4/parsecount-both-sides.md` |
| ③ 多重集比对 | `tests/parity/evidence/M4/multiset-gate.txt` |
| ① 宏边界 | `tests/parity/evidence/M4/macro-parity.txt` |
| ② NPC 用例 | `tests/parity/evidence/M4/npc-cases.txt` |
