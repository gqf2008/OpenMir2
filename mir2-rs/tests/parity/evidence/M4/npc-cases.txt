### 商店：商店-货币兑换（@changeGold 足额金币→金条）
- 脚本/label：`E:/MirServer/M2GameSvr/Envir/Market_Def/封魔谷/恶魔修理师-d2008.txt` `@changeGold`
- 初始状态：gold=1200000 items=金币:1:1,金条:2:1 player_items=
- 期望副作用：['take 金币 1002000', 'give 金条 1', 'MESSAGEBOX 金条已经为你换好了']
- 为什么等窗口：脚本首行是商人头 `(@buy @sell @repair @s_repair @storage @getback …)` ⇒ C# 参照 `ScriptParsers.LoadScriptFile` 在 `ScriptParsers.cs:713+` 把 NPC 转成 `IMerchant`；port-free 的 `tools/script-parity-cs run` 夹具（INormNpc）不含 IMerchant ⇒ 抛 InvalidCastException，无法做两侧行为对拍。
- 失败怎么判红：① 行为：同一 label/输入下，C# 与 Rust 的 take/give/messagebox 序列逐行相同（差 0）；② DB 作用域：角色 `Gold` 与背包/仓库物品行按 `tests/parity/m3/scoped_diff.py diff --canonical` 比对，作用域内字段级 diff = 0。任一非 0 即判红。
- 窗口释放后怎么跑：
  1. 见 `lane-status.log` + 端口，确认 5000/7000/7100/7200 空闲；
  2. 起两侧栈（C# 参照 / Rust），用与上表同一脚本、同一 label、同一初始状态交互；
  3. 行为 diff：逐行比 take/give/messagebox 序列；DB 作用域：
     `python -I tests/parity/m3/scoped_diff.py diff <a.jsonl> <b.jsonl> --canonical`；
  4. 把两侧原始输出与 DB 快照 hash 写入 `evidence/M4/npc-cases-window.txt`。
