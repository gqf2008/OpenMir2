## 1. 改法论证（卡片①的"二选一"）

`--axis-audit`（原始输出 `axis-audit.txt`）实测：

```
[条件] 成员 207；字段序号≠枚举值 0；两套键（字段序号 vs 枚举值）取值不同的成员 0；缺键 96
[动作] 成员 352；字段序号≠枚举值 0；两套键（字段序号 vs 枚举值）取值不同的成员 0；缺键 219

=== 现行口径下的命中检查（命令 → CmdCode → 处理器）
    OK   CHECKITEMADDVALUE      CmdCode=130  命中=ConditionOfCheckItemAddValue   期望=ConditionOfCheckItemAddValue
    OK   CHECKRANGEMONCOUNT     CmdCode=129  命中=ConditionOfCheckRangeMonCount  期望=ConditionOfCheckRangeMonCount
    OK   CHECKLEVEL             CmdCode=7    命中=ConditionOfCheckLevel          期望=ConditionOfCheckLevel
    OK   Give                   CmdCode=3    命中=ActionOfGiveItem               期望=ActionOfGiveItem
    OK   Set                    CmdCode=1    命中=ActionOfSet                    期望=ActionOfSet
```

- **否掉"改执行器查表口径"**：`GetFields()` 的字段序号与枚举值逐成员相等（含 `value__` 占位的口径一致），
  所以"按字段序号建键"与"按枚举值建键"是**同一张表**——改它不会改变任何派发结果，位移依旧。
- **否掉"查表时 +1"**：特判命令（条件 `CHECK`/`CHECKOPEN`/`CHECKUNIT`；动作 `Set`/`ReSet`/`SetOpen`/`SetUnit`/`ResetUnit`）
  的解析分支本来就存**正确**的 code（实测 `Set → ActionOfSet` 是对的），查表 +1 会把它们推到错误的处理器。
- **⇒ 只能改解析器的 `code - 1`**：改后普通命令与特判命令口径统一（都是字段序号），且由上面的实例检查
  逐条证明"命中自己的处理器"。

> 与上游的关系：B-8 的来源是上游 2023-06-15 的 `8a8a02d1`；本工程此前按"行为等价优先"刻意 1:1 复刻，
> 现在由本批次按 owner/协调者决定修掉（whitelist B-8 行已加注）。

## 6. 观察登记（含 S2 计数自纠）

1. **S2 计数自纠**：S2 报告 §2.1 与 `evidence/S2/probe-sweep-envir.txt` 里的"1433 行 100% 被位移"，
   是拿**处理器方法名**和**命令名**比出来的——两者命名法不同（`ConditionOfCheckItemAddValue` vs
   `CHECKITEMADDVALUE`），那个比法**恒真**，所以"100%"是假的。正确口径是比**两套规则算出的 CmdCode**
   （或两者命中的处理器）：**条件 1401/1433 + 动作 6239/6286 = 7640**，未变的 79 行用的是特判命令
   （它们的解析分支本来就存对）。S2 的结论（120 行必抛、不是夹具问题、被 NPC 层兜住）**不受影响**。
   探针已改（S3 起 `--sweep` 按两口径 CmdCode 判定），并把两种口径分列打印。
2. **GameSvr 起动依赖失败时报错误导**：DBSrv/LoginSrv 不在时，网关 `Initialize()` 被跳过，
   `TcpService.Start()` 报 `Config 为 null，请先执行 Setup`（看着像配置问题，实际是依赖没起来）。
   **属 oracle 起动健壮性**，本批只登记不修（与 S2 的两条工具问题同族：错误信息指向了错误的方向）；
   若 owner 要修，另立批次。
3. 本批**未做客户端级 E2E**（用真实客户端点「复原」看对话恢复）：该判据需要账号持有并**穿戴**祈福项链
   + 背包有祝福油的状态，成本高；而"修后行为"已由 B 线的真实 C# 工具（`script-parity-cs`，跑真脚本
   `比奇国王-0122.txt` 的 `@rw03`）逐行给出（§2.3）。如需真机留证，交 C 线夹具（他们有穿戴态夹具）。
