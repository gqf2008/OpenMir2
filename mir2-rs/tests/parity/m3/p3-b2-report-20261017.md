## 2. 期望表复算方法

- 取数记号与 max 按合同 §1.5；两个种子 `42` 与 `20261017`。
- 施法者侧 4 抽：`MPow` → `GetPower` → `GetAttackPower` 的 `Random(nPower+1)` + `R(10)`。
  `nPower` 实参：2/29 = `(Hi(SC)-Lo(SC))*2+1 = 17` ⇒ `R(18)`；23/24/33/47 = `Hi(MC)-Lo(MC)+1 = 11`
  ⇒ `R(12)`（合同 §5-C15 订正）。
- 交付段账本（seed 42，F-B2）：M1 `R(1000)=168, MSD=R(11)=2, R(300)=217`；M2 `512,1,228`；
  P1 `MSD=R(13)=3, STD R(10)=2`；M3 `505,0,114`（合同 §2.3(e)）。
- **实现侧复算**：测试用独立 `RandomNumber::with_seed(seed)` 按 oracle 语句序推进，再与
  `world.rng` 的 `Debug` 全状态逐项比较（不是只看单抽/总数）。用例
  `spell_p3b2_all_six_draw_sequences_match_contract_tables` 覆盖两种子 × 六魔号；
  `spell_p3b2_fireboom_delivery_ledger_and_frames` 覆盖 23 的交付账本与零伤害变体。
- 帧面：按 `(byte)RM_*` 优先级断言**不同优先级相对序**与**同优先级集合/条数**
  （合同 §1.6 允许的口径；同优先级内部堆序未建模）。

## 7. 与合同的偏离 / 未决项（逐条列明）

1. **交付段处理时点（构造级模型）**：oracle 的 `RM_MAGSTRUCK` 进**目标自己的** `MsgQueue`，在目标下一次
   `Run()` 处理；本仓在 `handle_spell_cmd` 的 B2 支内于共享尾之后**同步**逐目标完整处理
   （合同 §4.2 明示的构造级口径）。跨目标实际 interleaving / 目标 `Run()` 时序待真机窗口。
2. **同优先级帧序**：`SpellFrameBuf` 用**稳定**排序（同优先级 = 入队序）；oracle 是 .NET 4 叉堆序。
   合同 §1.6 允许「同优先级集合 + 不同优先级相对序」；逐帧堆序待窗口抓取（R 级 `not_verified`）。
3. **`RushMode` 无字段**：`Entity` 未建模 `RushMode` ⇒ 交付段 `R(1000)` 条件恒按 `false`
   处理（合同 §3.1 pin；若将来接入 Rush，必须回到本处）。
4. **`Invisible` 折叠（合同 §6-6 / C13）**：`combat::is_proper_target_grouped` 顶部折入
   `target.invisible`，oracle `IsProperTarget` 不读 `Invisible`。本片保留折叠并登记；夹具的 AoE
   目标**不使用** invisible。若窗口需要「命中 invisible 目标」，须先改折叠口径。
5. **`GetMagStruckDamage` 的 undead 加项**：`RM_MAGSTRUCK` 处理器传 `null` ⇒ 不生效（已按此实现）。
   `MonDelHptoExp=true` 时 oracle 会传真实攻方并**额外多一次 MSD 抽**；本片 pin 缺省 `false`，
   未建模该支。
6. **`MonSayMsg` / `DisableStruck` / `DisableSelfStruck`**：缺省 false（`Server.conf:376/346/766=0`），
   未建模其支；`MonSayMsg=true` 会对 `SayMsgList` 每条匹配抽 `Random(nRate)`。
7. **`StruckDamage` 的职业/主人倍率**：`WarrMon/WizardMon/TaosMon/MonHum` 配置缺省均 10
   ⇒ 数值不变；本层未读非缺省配置。夹具 `LastHiter=null`。
8. **玩家 `STD` 的物品破坏副作用**：只复刻 RNG（`R(10)` + 每格 `R(8)`）与耐久数值；
   `SendDelItems`/`FeatureChanged`/`RecalcAbilitys`/`RM_DURACHANGE` 帧面未接（既有登记）。
9. **`RM_MAGIC_LVEXP` 仍即时发**：延迟面沿用既有全局登记（`SendSelfDelayMsg` 1000ms）；
   本片只扩了队列载荷（`w_param/n_param1`）并让 `RM_MAGHEALING` 走 800ms。
10. **`AbilSeeHealGauge` 无生产写点**：技能 28（心灵启示）未移植 ⇒ 生产恒 false；字段已就位，
    测试可显式置 true。
