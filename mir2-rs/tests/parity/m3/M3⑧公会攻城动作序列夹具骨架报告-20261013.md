## 2. 判据口径（与盘点 §4.1 五条对齐）

1. **逐 `(bot,k)` 对齐**：两侧必须有同一组 bot、每个 bot 同一串 k；否则 RED（fail-closed）。
2. **帧种类序列**（严格顺序）：`750/753/754/756/757/758/759/760/761/762/763/767/768/769/770/771/10303/10304`；
   动态 id 不作判据。
3. **声明标量**（Recog 失败码）：`SM_GUILDADDMEMBER_FAIL(758.a)` / `_DELMEMBER_FAIL(760.a)` /
   `_RANKUPDATE_FAIL(761.a)` / `SM_BUILDGUILD_FAIL(763.a)` / `_MAKEALLY_FAIL(769.a)` / `_BREAKALLY_FAIL(771.a)` /
   `RM_BUILDGUILD_FAIL(10304.a)` 等（比较器缺省 `frame_scalar_fields`，场景文件同源）。
4. **文本帧逐字节**：`SM_CHANGEGUILDNAME(750)` / `SM_OPENGUILDDLG(753)` / `SM_SENDGUILDMEMBERLIST(756)` /
   `SM_MENU_OK(767)`。
5. **行会名/封号名**：`guild_name`/`guild_rank_name`（来自 `SM_CHANGEGUILDNAME` 回包写入的
   `MShare.g_sGuildName/g_sGuildRankName`）；`members_*`/`bag_*` 按多重集。
6. **落库（= 不落库）**：`scoped_diff.py diff --canonical` 增量 0；行会/攻城的持久产物是**文件**
   （`GuildBase/GuildList.txt`、`GuildBase/Guilds/<名>.txt`、`Castle/<N>/SabukW.txt`、`AttackSabukWall.txt`），
   窗口期两侧同目录同种子比。
7. **branch**：`ok` / `fail_reject` / `skip_other_role` / `fail_no_frame` / `frames_unclassified`；
   `observe`/`wait` 固定 `ok`。
