### 1.1 16 捆魔咒（`SKILL_HOLYSHIELD`）

- 组前置：`MagicManager.cs:322 boSpellFail=true` → `:323 CheckAmulet(1,1)` → `:325 UseAmulet(1,1)`；
  门不过 ⇒ `:644-647 return false` ⇒ 调用方恰一条 `SM_MAGICFIRE_FAIL(639)`，零抽、无 642/638/640。
- 实参 `GetPower13(40) + GetRPow(SC)*3` **先于** helper 求值（F16-D 也能看到这两抽）。
- helper（`:1149-1176`）：`CanWalk(tx,ty,true)` 失败 ⇒ 0；`GetMapBaseObjects(...,1)` 空 ⇒ 0；
  逐对象：`Race>=Animal` 失败 ⇒ 不抽、`result=0`；通过 ⇒ **必抽 `R(4)`**，再判
  `R(4)+caster.Level-1 > obj.Level && Master==null`，失败 ⇒ `result=0`（**已入队的帧不回滚**）。
  ⇒ 最终 `result` = 最后一段连续合格对象的数量。
- 合格对象 `SendMsg(RM_MAKEHOLYSEIZEMODE, nPower*1000)` ⇒ 目标自己队列处理时

  计算 ⇒ 怪的 `name_color`（`BaseObject.cs:385` 构造置 **255**）。`MonsterObject.GetChrColor` 的
  `HolySeize ⇒ 0x7D` 分支在本处理器不可达。
- 实现：`World::cast_holy_curtain_spell`（`world.rs`）+ `magic_effect::holy_curtain_draw`；
  `World::open_holy_seize_mode` 落 `ai.holy_seize/holy_seize_tick/holy_seize_interval`。

### 1.5 32 圣言术（`SKILL_KILLUNDEAD`）

    `SetLastHiter` + `HP=0` + `result=true`。
- 类型面：目标为玩家（非 `AnimalObject`）且 `LA_UNDEAD` ⇒ oracle 抛 `InvalidCastException`，
