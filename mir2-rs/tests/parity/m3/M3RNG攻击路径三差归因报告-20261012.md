## §1 oracle 真身单次攻击的取数模型（探针实测，非源码重推）

探针直调真身 `PlayObject.AttackDir(IActor, short, byte)`（`PlayObject.Attack.cs:25`，protected，反射），
`RecordingRandom` 按 `seq|kind|arg|result|site` 记账（与 D2 `RngSeedHook` 同形）。
完整逐次账本见 `evidence-attack-dir-20261012/01-per-attack-draw-ledger.txt`。

**玩家（`Race == Play`，`Luck == 0`）一次攻击的取数次序**：

| 步 | 站点（oracle） | 抽取 | 条件 |
|---|---|---|---|
| 1 | `PlayObject.GetAttackPower@PlayObject.cs:2929` | `Random(power+1)` | 必有（`GetBaseAttackPoewr` → 虚调用 override，`PlayObject.Attack.cs:73`） |
| 2 | `PlayObject.GetAttackPower@PlayObject.cs:2932` | `Random(10)` | `Luck <= 0` 必有（`PlayObject.cs:2932`） |
| 3 | `BaseObject._Attack@BaseObject.Attack.cs:41` | `RandomByte(target.SpeedPoint)` | **仅当** `IsProperTarget && target.HitPoint > 0` |
| 4 | `BaseObject.GetHitStruckDamage@BaseObject.Base.cs:792`(/:795) | `Random(\|ΔAC\|+1)`（+ 若 `nRnd>0` 再 `Random(nRnd)`） | 仅当 `nPower > 0`（命中） |
| 5 | `PlayObject.StruckDamage@PlayObject.cs:2957`(/:3000) | `Random(10)` + 每个已装备格 `Random(8)` | 仅当伤害落到**玩家**目标 |
| 6 | `PlayObject.AttackSuccess@PlayObject.Attack.cs:225` | `Random(5)` | **目标非空时必有**（命中/躲闪都抽） |

⇒ 本片新增的站点是 **第 6 步**（此前 Rust 完全没有）。探针四例的每击抽数：
- `no_target_power_only`：**2**（只有第 1、2 步）；
- `target_miss`：**4** = 2 + 命中门 1 + `AttackSuccess` 1；
- `target_hit_ac0`：**5** = 2 + 命中门 1 + 护甲 1 + `AttackSuccess` 1；
- `target_hit_ac2`：**6** = 2 + 命中门 1 + 护甲 2 + `AttackSuccess` 1。

## §2 ① `hit_gate` C# 9 vs Rust 36

- **oracle 门链**：`BaseObject._Attack`（`BaseObject.Attack.cs:30`）里
  `if (IsProperTarget(targetObject)) { if (targetObject.HitPoint > 0) { if (HitPoint < RandomNumber.RandomByte(targetObject.SpeedPoint)) nPower = 0; } }`
  （`:37-44`）⇒ **每击至多 1 次** `RandomByte`，且 `IsProperTarget` 为假或目标 `HP<=0` 时为 **0 次**。
  真身向量已坐实（§1 第 3 步）。
- **为什么 C# 是 9、Rust 是 36**：这是**带目标攻击数**不同，不是每击抽数不同。
  - C# 120 段里只有 **5 段**带 `hit_gate`（2 闪避 + 2 命中 + 1 混入噪声），其余 **115 段**是 `[atk_power_a, atk_power_b]`（无目标）；另有 4 次段外预热 `atk_power_base, hit_gate, hit_struck_damage` ⇒ 合计 9。
  - Rust 36 段**每段**都有 `hit_gate` ⇒ 36。
- 该「带目标攻击数」面属**接线/AOI 取目标**（`bins/game-svr/src/main.rs` 的 `handle_hit_cmd`），本片只给 `.rs` 侧归因（见 §4）。

  `AttackSuccess(wHitMode, nPower, canHit, attackTarget)`（`:77`）；目标非空即**无条件**抽一次
  `Random(5)`（`:225` `nWeaponDamage = (ushort)(Random(5) + 2 - AddAbil.WeaponStrong)`，记录站点 `:223`）。
  **命中/躲闪都抽**。其余 `AttackSuccess` 取数（`:221` 麻痹、`:254/:261`/`TrainCurrentSkill` 技能熟练度）
  依赖 `Paralysis`/`MagicArr` 运行态，本骨架未建模 ⇒ 登记（不静默）。
- **改前**（`crates/world/src/combat.rs`）：`World::attack_once` 调 `attack_with`，只有 `GetBaseAttackPoewr` + `_Attack`，
  **没有** `AttackSuccess` 那一抽。
- **改后**：新增 `attack_success_weapon_damage`（`combat.rs:830`，`rng.random_below(5)`）与
  `attack_dir`（`combat.rs:848`，= 按 `Race` 选 `AttackPowerMode` 的 `attack_with` + 玩家攻方追加 `attack_success_weapon_damage`）；
  `World::attack_once`（`world.rs:658`）改调 `attack_dir`。**`attack_with` 保持 `_Attack` 口径不变**（`combat-probe` 真身向量不含 `AttackSuccess`，见 §5）。
- **向量 + 红检**：

### ②-2 `atk_power_base`（不是玩家攻击路径，用原始件说明）

- **oracle**：`atk_power_base` 站点 = `BaseObject.GetAttackPower@BaseObject.Base.cs:892`（基版）。
  `GetBaseAttackPoewr` 调**虚函数** `GetAttackPower`：`Race == Play` 走 `PlayObject.cs:2909` override
  （记为 `atk_power_a/b`），**非玩家**（怪物等）无 override，走基版（记为 `atk_power_base`）。
- **C# 窗口里的 5 次**：`expr` 显示 4 次在首击（`atk_power_a`）**之前**、1 次插在玩家段内
  （`26-csharp-segments.txt` 的那条 `[.., atk_power_base, hit_gate, hit_struck_damage]`）——那是**别的图里怪物攻击**
  交错进来的取数（本窗口 C# 全局随机源被 70 个非攻击站点共享，噪声占 99.94%），**不是** 2-bot PvP 攻击路径的站点。
- **Rust**：已按 `Race` 分派（`AttackPowerMode::for_attacker`，`combat.rs`）⇒ 玩家走 override、怪物走基版，
  实现与 oracle 同形，**无缺口**。

## §4 ③ 段数 120 vs 36 + `World::attack_swing`

- **C# 115/120 段是 `[atk_power_a, atk_power_b]`**：`PlayObject.AttackDir`（`PlayObject.Attack.cs:73`）在
  **取目标之前**先算 `GetAttackPowerHit(wHitMode, GetBaseAttackPoewr(), attackTarget, ref canHit)` ⇒
  即使 `attackTarget == null`（前方格无目标），`GetBaseAttackPoewr()` 的两抽**照抽**；
  之后 `_Attack(null)`（`BaseObject.Attack.cs:32`）立刻 `return false`、`AttackSuccess(…, null)`（`:215`，开头 `return`）都不抽。
- **Rust `.rs` 根因**：`World::attack_once` 只在 `entities.get(target_id)` 存在时结算（无「无目标」入口），
  接线 `handle_hit_cmd` 在无目标时只记日志（`main.rs` 的「只播动作帧（oracle `_Attack(null)` 返回 false）」支）——
  该日志的 oracle 引用**只说到 `_Attack`，漏了其前的 `GetBaseAttackPoewr`**。
- **本片 `.rs` 侧处置**：新增 `World::attack_swing(actor_id)`（`world.rs:186`）——只抽攻击力（玩家 2 抽、怪物 1 抽），
  不抽命中门（`_Attack(null)` 早退）、不抽 `AttackSuccess`（目标 null 早退）。单测
  `combat_skill_vectors.rs::world_attack_swing_draws_power_without_target` 用 `CountingRng` 钉住「恰 2 抽、无命中门」。
- **接线（m2-svr 写集，本片不改 `bins/**`）**：`bins/game-svr/src/main.rs` 的 `handle_hit_cmd` 无目标支
  必须改调 `world.attack_swing(actor_id)`，否则那 115/120 击的 `atk_power_a/b` 在 Rust 活栈账本里整段缺失。
  （「带目标攻击数」差同样在该文件的取目标段。）
