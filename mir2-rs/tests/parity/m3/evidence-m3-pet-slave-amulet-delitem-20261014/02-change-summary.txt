## 2) bins/game-svr/src/slave.rs（+132）

新增帧体构造器（模块头把「登记未接」改为「已接」）：

```rust
#[must_use]
pub fn deleted_amulet_body(actor_id: i32, item: &BagItem, catalog: &dyn ItemCatalog) -> Option<Vec<u8>> {
    let tpl = catalog.get(item.index)?;                    // SendDelItems 的 if (stdItem != null)
    let mut name = item_display_name(catalog, item);       // CustomItemSystem.GetItemName
    if tpl.std_mode == 50 { name = format!("{name} #0"); } // " #" + Dura，而 Dura 已置 0
    let ci = itemwire::ClientItem { tpl, name, make_index: item.make_index,
                                    dura: 0, dura_max: item.dura_max, desc: item.desc };
    let tail = edcode::encode(&itemwire::encode_client_item(&ci));
    Some(smframe::sm_delitem(actor_id, &tail))
}
```

- `dura: 0` 是**照搬语句序**的结果（oracle `:123` 先置 0 再 `:124` 发帧），不是近似。
- **无** `StdModeMap` 的 `Desc[8]`⇒`Shape`(0/130) 改写（`SendDelItems` 不动 `Shape`，与 `SendAddItem` 不同）。
- 新增单测 `deleted_amulet_body_encodes_delitem_with_zero_dura`：普通护身符逐字节 + `StdMode==50` 的
  `"药 #0"` 后缀 + 模板缺失 ⇒ `None`。

## 调用点/遍历序影响

- **零并行**：无新任务/无迭代序变化。
- **RNG 账本**：本片不调 `world.rng`（`use_amulet`/`encode_client_item` 均为纯函数），

  测试断言扣光支**不**发 `SM_DURACHANGE`。
