## A. 效果体：MagicBase.UseAmulet（src/M2Server/Magic/MagicBase.cs）

```
109:        public static void UseAmulet(PlayObject playObject, byte nCount, byte nType, short idx)
110:        {
111:            if (playObject == null)
112:            {
113:                return;
114:            }
115:            ushort duration = (ushort)(nCount * 100);
116:            if (playObject.UseItems[idx] != null && playObject.UseItems[idx].Dura > duration)
117:            {
118:                playObject.UseItems[idx].Dura -= duration;//减少护身符持久即数量
119:                playObject.SendMsg(playObject, Messages.RM_DURACHANGE, idx, playObject.UseItems[idx].Dura, playObject.UseItems[idx].DuraMax, 0);
120:            }
121:            else
122:            {
123:                playObject.UseItems[idx].Dura = 0;
124:                playObject.SendDelItems(playObject.UseItems[idx]);
125:                playObject.UseItems[idx].Index = 0;
126:            }
127:        }
```

要点：
- `:116` 的距离门是**严格 `>`** ⇒ `Dura == nCount*100` 走 else（扣光支）。配合 `CheckAmulet`
  的 `Round(Dura/100) >= count`（`MagicBase.cs:47-105`）⇒ 扣光支的可达域 = `count*100 >= Dura >= (count-0.5)*100`。
- **语句序**：`:123` 先把 `Dura` 置 0，**再** `:124` `SendDelItems` ⇒ 帧内 `Dura` **恒 0**；
  `:125` 最后清 `Index`（帧构造用的 `Index`/`MakeIndex`/`DuraMax`/`Desc` 仍是原件）。

## B. 帧构造：PlayObject.SendDelItems（src/M2Server/Player/PlayObject.Base.cs）

```
1648:        public void SendDelItems(UserItem userItem)
1649:        {
1650:            StdItem stdItem = SystemShare.ItemSystem.GetStdItem(userItem.Index);
1651:            if (stdItem != null)
1652:            {

1658:                clientItem.DuraMax = userItem.DuraMax;
1659:                if (stdItem.StdMode == 50)
1660:                {
1661:                    clientItem.Item.Name = clientItem.Item.Name + " #" + userItem.Dura;
1662:                }
1663:                ClientMsg = Messages.MakeMessage(Messages.SM_DELITEM, ActorId, 0, 0, 1);
1664:                SendSocket(ClientMsg, EDCode.EncodeBuffer(clientItem));
1665:            }
1666:        }
```

要点：
- 头字段位（`Messages.MakeMessage(ident, recog, param, tag, series)`）：`Recog = ActorId`、`Param = 0`、
  `Tag = 0`、`Series = 1`。
- 尾 = `EDCode.EncodeBuffer(clientItem)` = `Encode(ClientItem.WritePacket())`（与 `SM_BAGITEMS` /
  `SendAddItem` 同编码器；本仓 `bins/game-svr/src/itemwire.rs::encode_client_item`）。
- **与 `SendAddItem`（`PlayObject.Base.cs:198-227`）的差异**：`SendDelItems` **不做**
  `if (M2Share.StdModeMap.Contains(item.StdMode)) { Item.Shape = Desc[8]==0 ? 0 : 130; }` 的 Shape 改写；
- 立即帧：`SendSocket` 直写（`BaseObject.Socket.cs`），**不进** `MsgQueue` ⇒ 无优先级/出队序问题。
