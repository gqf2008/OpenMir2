# 改动摘要

## 旧口径（假绿通道，reviewer-5 F-1）

`check_anchors.py` 的符号唯一性锚用 `n = sum(1 for line in lines if re.search(a["rx"], line))`
统计 —— 数的是**匹配行数**：同一物理行写两遍期望符号（如 `spawn(); spawn();`）只计 **1** 次，
于是 `n == 1` 放行，**`ANCHOR_AMBIGUOUS` 不触发**。

## 本片修法（按「匹配总次数」计）

```python
n = sum(len(re.findall(a["rx"], line)) for line in lines)
```

同一物理行两遍符号 ⇒ n = 2 ⇒ `ANCHOR_AMBIGUOUS` 必红。0 次仍 ⇒ `ANCHOR_SYMBOL_MISSING`。
