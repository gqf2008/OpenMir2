# M3 受击耐久：衣服位（`Index 0`）特判与逐格 `Random(8)` 取数对齐报告（2026-10-12）

- 卡：`openmir2-m3-combat-skills-align`（issue `a2ef74aa`）／principal `openmir2-worker-5`
- worktree：`.claude/worktrees/m3cs`／branch `worktree-m3-combat-skills`

## 1. 问题

reviewer-5 指出：`PlayObject.StruckDamage`（`src/M2Server/Player/PlayObject.cs:2954`）的**衣服位
（`ItemLocation.Dress = 0`）特判**——「无条件扣耐久 + 破零置 `Index = 0`」——在 Rust 侧未建模。
后果：装备耐久被打断后，C# 会先把 `Index 0` 清掉，从而**跳过该格的 `Random(8)` 抽数** ⇒ Rust 与 C#
的**全局 RNG 流会分叉**。旧夹具没有装备、也未打断 ⇒ 未触发；一旦真机跑进「打断耐久」这条路径，
它就会变成逐 k 差异。

## 2. oracle 读全（行号 + 语义）

`PlayObject.StruckDamage` override 在 `base.StruckDamage` 之后：

| 行 | 语义 |
| --- | --- |
| `:2957` | `ushort nDam = (ushort)(Random(10) + 5);` —— **无条件**抽一次 `Random(10)` |
| `:2958-2961` | `StatusTimeArr[DAMAGEARMOR] > 0` 的 1.2 倍分支（本骨架无 buff，未建模） |
| `:2965-2996` | **衣服位特判**：`if (UseItems[0] != null && UseItems[0].Index > 0)` —— **不抽数** |
| `:2967-2969` | `nDura = UseItems[0].Dura; nOldDura = Round(nDura/1000.0); nDura -= nDam;` |
| `:2970` | `if (nDura <= 0)` —— `nDura` 是 `ushort` ⇒ 等价于 `nDura == 0` |
| `:2982-2986` | 破零：`Index = 0` + `FeatureChanged()` + `Index = 0` + `Dura = 0` + `boRecalcAbi = true` |
| `:2990` | 未破零：`UseItems[0].Dura = nDura` |
| `:2998-3039` | **逐格循环**：`UseItems[i] != null && Index > 0 && Random(8) == 0` ⇒ 扣耐久，破零同样清 `Index`（`:3008`/`:3012`） |

两点易错：

1. **`ushort nDura -= nDam` 是 unchecked 回绕**（工程默认 `CheckForOverflowUnderflow=false`，
   `Directory.Build.targets` 未开启 checked）⇒ `Dura < nDam` 时结果是**大正数**，**不破零**；
   只有 `Dura` **恰好等于** `nDam` 才破零。
2. 衣服位特判在逐格循环**之前** ⇒ 破零清 `Index` 使循环**跳过 slot 0 的 `Random(8)`**：同一击里
   取数次数少 1，全局 RNG 流从该击起错位。

## 3. Rust 侧建模

`crates/world/src/combat.rs`：

```rust
pub const ITEM_LOCATION_DRESS: usize = 0;

fn wear_durability(slot: &mut UseItemSlot, n_dam: u16) {
    let next = slot.dura.wrapping_sub(n_dam);   // 复刻 unchecked ushort
    if next == 0 { slot.index = 0; slot.dura = 0; } else { slot.dura = next; }
}

pub fn struck_damage_durability(rng: &mut impl RandomSource, target: &mut Entity) {
    if target.race != ACTOR_RACE_PLAY { return; }        // 怪物走 BaseObject.StruckDamage（无随机数）
    let n_dam = (rng.random_below(10) + 5) as u16;       // :2957
    let dress = &mut target.use_items[ITEM_LOCATION_DRESS];
    if dress.index > 0 { wear_durability(dress, n_dam); } // :2965-2996（不抽数）
    for slot in target.use_items.iter_mut() {              // :2998-3039
        if slot.index > 0 && rng.random_below(8) == 0 { wear_durability(slot, n_dam); }
    }
}
```

`attack_with` 对玩家目标改调 `struck_damage_durability`（怪物目标直接返回，行为不变）。
未建模且不影响取数的部分：`SendDelItems`/`FeatureChanged`/`RecalcAbilitys`/`SendMsg(RM_DURACHANGE)`
（帧面，本骨架不落）；`DAMAGEARMOR` 1.2 倍分支（无 buff 状态）。
