## 1. 决策片要回答的问题

> 噪声抽取有没有夹在攻击路径的两次取数之间？
> 有 ⇒ 攻击窗口前两侧同步重播种就能救；没有（噪声都在窗口外）⇒ 重播种也不够，必须升级到
> 「1:1 建模 oracle 的消费者」或别的隔离手段。

## 2. 已交付仪器（Rust 半）

- **落点 = 全局随机源本身**：`crates/shared/src/rng.rs::RandomNumber` 的每个取数入口（`random/below/range/
  get_random_number/random_byte/generate_random_number/random_select/next_double`）旁路记录；`#[track_caller]`
  把 site 传到**世界层调用点**（实测 `crates\world\src\combat.rs:109`），不是 `crates/shared` 包装层。
- **形态 = 与 C# `rng-hook` 逐列同形**：`seq \t kind \t arg \t result \t site`，头两行 `INJECT_OK <seed>` /
  `SEED_PROBE …`。落盘用 `LineWriter` 逐行 flush（进程被强杀不丢行）。
- **开关 = 环境变量 `MIR2_RNG_LOG`（沿用 C# 同名）+ 自证读 `MIR2_RNG_SEED`**：两者缺一/种子非法 ⇒ 不开启并点名报错。
  **未设 ⇒ 取数只多一个 `AtomicBool` 读，值序列逐字节不变**。
- **接线零改动**：`bins/game-svr` 生产路径已调 `RandomNumber::with_seed(seed)`（T-30），`with_seed` 内自动
  `enable_from_env()`；起栈时 `Start-Process` 默认继承调用方环境 ⇒ **只差在起栈 shell 里设一次 `MIR2_RNG_LOG`**，
  **不改 `bins/game-svr` 一行**。
- **用例**：`crates/shared/tests/rng_trace.rs`（off vs on 值逐项相同 + 同形 + 改坏一行 result 必红）。

## 3. 读数与定位

### 3.1 C# 全局随机源：噪声占 99.98%，且**夹在攻击取数之间**

原始件 `01`（m3bag 账本 summary）、`03`/`04`（本片分析器）、`06`（原始行摘录）：

```text
RNG_LEDGER_SUMMARY total=1,670,754  attack_path=275  noise=1,670,479  noise_ratio=0.9998
RNG_TRACE_INTERLEAVE marker=M2Server.Player.PlayObject.GetAttackPower@PlayObject.cs:2929 attacks=120
  intra_noise_attacks=3/120        # 同一击内部两次取数之间夹噪声
  internal_noise_max=13
  inter_attack_noise min=807 median=1777 max=3284   # 击与击之间的噪声
  VERDICT: INTERLEAVED
```

- **同击内交错**（`06`，`#2`）：
  `223799 GetAttackPower@2929 → 223800 GetAttackPower@2934 → 223801 AnimalObject.Wondering@427 → 223802 _Attack@41 → … → 223815 GetHitStruckDamage@792`。
  `#3`：`225618/225619/225621/225623/225625/225627` 六步之间**各夹 1 条 `AnimalObject.Wondering@427`**。
- **击间噪声**：每两击之间 min 807 / median 1777 / max 3284，`>1000` 的 114/119。
- **噪声来源**（`05`，均为**其它地图/系统**的并发消费者，0137 本身零刷怪）：
  `AnimalObject.Wondering` 1,060,321+53,169+13,384、`MonGetRandomItems` 195,913+9,183、
  `Merchant.Run` 128,717+126,096、`RegenMonsters` 13,774、`CreateMonster` 6,936、`AnimalObject..ctor` 14,180、
  `BaseObject..ctor` 7,090×2。

### 3.2 Rust 生产路径：没有这些消费者

原始件 `08`/`09`：Rust 离线单线程跑攻击路径（`combat_skill_vectors`，seed=42，trace 同形落盘）：

```text
RNG_TRACE_INTERLEAVE marker=crates/world/src/combat.rs:109 attacks=2996
  intra_noise_attacks=0/2996
  attack_draw_gap_histogram={'0': 11950}
  inter_attack_noise min=0 median=0 max=0
  VERDICT: CONTIGUOUS
  (summary: attack_path=14946 noise=0 noise_ratio=0.0000)
```

⇒ 两侧流位置从**第一次攻击**起就分叉：Rust 只抽攻击路径，C# 的同一位置被其它系统插了成百上千次。
这解释了 `attack_diff.py diff` 的 **Rust 19 击 vs C# 1 击 / 83 项**（残差② Dir 是叠加因素，已由 m2-svr 修）。

## 4. 修法选项（不替 owner 决定）

| 选项 | 内容 | 代价/影响面 | 能否把 DoD② 拉到逐 k=0 |
|---|---|---|---|
| **(a) 攻击窗口前两侧同步重播种** | C# `rng-hook` 加 `Reseed(seed)`（夹具/工具链写集，可加）；Rust `RandomNumber` 加重播种；两侧同一哨兵触发 | 中：夹具语义改造（`T-*` 登记），需两侧同步触发点；**偏离 oracle**（真服不重播种） | **否**：消得掉击间 ~1777 条噪声，但 `#2/#3/#55` 这类**同击内跨线程交错**仍分叉（实测 3/120） |
| **(b) 1:1 建模 oracle 非攻击消费者** | 把 §3.1 缺口（怪 AI / 商人 / 刷怪 / 构造期）按 tick 顺序在 Rust 建世界时复刻 | **高**：等于把「谁会抽随机数、按什么顺序抽」全部对齐；还要复刻 C# **多线程交错次序** | 原则上可，但成本是独立里程碑，远超 ②③ 收口 |
| **(c) 隔离测量窗口** | (c1) DoD② 判据落在**离线单线程探针口径**（`attack-hit-probe`/`combat-probe` + `combat_skill_vectors`）；(c2) 真机运行期静默其它 RNG 消费者；(c3) 保留真机逐 k、按 §6.0-3 登记为不可达 | (c1) 低、已具备；**改判据口径 ⇒ 必须 owner 签字登记**；(c2) 高且仍不解决跨线程插入；(c3) 只登记不解决 | (c1) **可以**（零噪声、确定性、两侧 1:1 可对拍）；(c2)/(c3) 否 |

**本片倾向 (c1)**：`attack-hit-probe` 已把「固定种子 → 反射直调 oracle 攻击路径」跑通，Rust 侧对应用例
本片实测零噪声；把逐 k 判据落在探针口径即可得到**有仲裁力的逐 k=0**。但这是**判据变更**，
按 §6.0-3 只能**带证据请 owner 签字登记**，本片不改。
