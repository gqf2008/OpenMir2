tick / 调用点接线
- `World::tick()`：`settle_deaths` 之后跑 `slave::slave_list_cleanup_all(self)`（空表零动作；golden 逐字节不变）。
- `monai::monster_run`：在 oracle `MonsterObject.Run` 的两个「落到 CheckRoyalty」口（外层 `CanMove` 假、`WalkWait`/`WalkSpeed` 门假）
  与函数尾各调一次 `slave::check_royalty`；`Think()`/`AttackTarget()` 的提前返回处**不调**（与 oracle `:255-258/:277-283` 同）。
- `World::tick()` 的怪物 AI 步（`ai_enabled`）驱动 `CheckRoyalty`；缺省 `ai_enabled=false` 时 AI 与 CheckRoyalty 都不跑（既有口径）。

照搬的 oracle 缺陷（`BUG-REPLICA`；本仓约定：⑨-2 同款在代码模块头 + 本 README 登记，T-* 编号归属待 owner 裁决）
1. 色表越界门：`GetChrColor` 用 `<= SlaveMaxLevel(50)` 索引 15 项 `SlaveColor` ⇒ 15..=50 latent `IndexOutOfRange`；
   Rust 用 `slice::get` 落 `GetNameColor` 兜底（正常数据不可达：召唤等级 ≤ `SlaveMakeLevel*2+1`；`ProcessSlaveMutiny` 置 15 但同置 `Master=null`）。
2. `MasterDieMutinySpeed == 0` 除零：oracle `WalkSpeed / Config.MasterDieMutinySpeed` 在配置缺陷（读 `MasterDieMutinyPower` 键）
   下若 Power=0 会抛除零；Rust `speed != 0` 才除（不可达分支，登记）。
3. `GainSlaveExp` 死代码：全仓无调用点 ⇒ 击杀不涨 `SlaveExpLevel`，本片不实现。
4. `DC` 缩放截断：`WAbil.DC = (ushort)MakeLong((short)(LoByte*Power),(short)(HiByte*Power))` 的外层 `(ushort)`
   丢掉高 16 位 ⇒ `DC` 实际只等于 `(ushort)(short)(LoByte*Power)`，高字节归零。Rust 逐位保留（专测钉住）。
