## 2. 判据③·新增：39（`SKILL_GROUPDEDING` → `MagGroupDeDing`）群体物理伤害

数据行名 = 「乌龟跑步」（job 99），但 oracle 按**魔号**分派（与数据行名无关）——本实现照搬 oracle。

逐目标表达式（`src/M2Server/Magic/MagicManager.cs:960-968`，case 标签 `:549`）：

```csharp
int nPower = playObject.GetAttackPower(HUtil32.LoByte(playObject.WAbil.DC), HUtil32.HiByte(playObject.WAbil.DC) - HUtil32.LoByte(playObject.WAbil.DC));
if (M2Share.RandomNumber.Random(baseObject.SpeedPoint) >= playObject.HitPoint) nPower = 0;
if (nPower > 0) nPower = baseObject.GetHitStruckDamage(playObject, nPower);
```

三点与普攻 `_Attack` **不同**（易抄错，已逐字复刻）：

1. 第二参是 `Hi(DC) - Lo(DC)`：**不做 `(sbyte)` 强转、也不 `+1`**（普攻 `GetBaseAttackPoewr` 会 `(sbyte)` 且 `+1`）；
2. 闪避判定是 `Random(target.SpeedPoint) >= attacker.HitPoint`（普攻是 `attacker.HitPoint < RandomByte(target.SpeedPoint)`，方向相反）；
3. `Random(SpeedPoint)` 在**攻击力之后无条件**抽一次（进取数账本）。

- 探针（真身）：真 `PlayObject` 攻方 + 真 `MonsterObject` 目标（`AC=0x0A05`、`SpeedPoint=40`、
  `LifeAttrib=0`），直调 `caster.GetAttackPower` / `target.GetHitStruckDamage`。
- 向量（seed `20261012`，子种子 `seed ^ 39`）：`power=20`、`armor 后 damage=14`。
  两侧逐字段相等；`group_melee.damage` 红检可判红（见 §4）。
- Rust：`crates/world/src/magic.rs::group_melee_damage`（返回 `(闪避前 power, 护甲后 damage)`）。

## 3. 判据③·登记收口：DoSpell 全表分派分类（机器可判，不许静默漏）

原登记只给一个「未实装」的笼统理由。本片按 oracle `DoSpell` 的**控制流**把真魔表 108 行**逐行**

| 类别 | 口径（`MagicManager.cs`） | 行数 |
| --- | --- | --- |
| `warr_reject` | `IsWarrSkill(MagIdx)` ⇒ `return false`（`:82-105,151`） | 8 |
| `magicid_reject` | `MagicId > 80` ⇒ `return false`（`:167`） | 35 |
| `implemented` | 本片有用例（前置/MP/效果/冷却四字段齐备） | 29 |
| `context_required` | 有 case，但效果需地图/目标/可见集/召唤/状态 | 10 |
| `no_effect_case` | 有 case，但体内无副作用（`break` / 只置 `boTrain`） | 6 |
| `no_switch_case` | `switch` 无此魔号分支 | 20 |

- `context_required` 的 10 个魔号：`8 抗拒火环`、`17 召唤骷髅`、`20 诱惑之光`、`21 瞬息移动`、

  （承接 = M3 攻击/魔法接线后的批次：`MagPushArround`/`MagMakeSlave`/`MagTamming`/`MagSaceMove`/
  `MagTurnUndead`/`MagMakeClone` 的遍历与施加都需要地图/目标态）。
- `no_effect_case`：`43 开天斩`（`break`）、`49 云寂术`、`51-54`（只 `boTrain=true`）。
- `magicid_reject`：`81-103`（含 `91-94` 的重复行）+ `500/501`。
- `no_switch_case`：`55-59`、`66-69`、`71`、`72`、`74-80`（≤80 且非 warr、无 case）。
- **机器门禁**：`dospell_classes_are_fully_registered` 断言 108 行、每行类别合法、`implemented`
  行类别必须为 `implemented`，并**逐类钉死行数**（内容冻结 ⇒ 行数稳定；新增/漏登魔表行即 RED）。

> 口径纪律：分类是 **source-cited**（逐条抄 `DoSpell` 的 `switch` case 集合 + 真身调用
> `MagicManager.IsWarrSkill` + `MagicId>80` 门），不是「按名字猜测」；`warr_reject`/`magicid_reject`
> 由真身函数算出，`context_required`/`no_effect_case`/`no_switch_case` 的集合在此逐条钉出。
