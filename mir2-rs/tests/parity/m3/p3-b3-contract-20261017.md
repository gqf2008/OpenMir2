### 2.2 收件人语义（必须逐字复刻）

1. `SendRefMsg`（`BaseObject.Message.cs:383-449`）：
   - 若 `ObMode || FixedHideMode` ⇒ 只发给自己（`:390-393`）；
   - 否则扫 `CurrX±SendRefMsgRange`（默认 12）× `CurrY±12` 的格子：`CellMatch` 失败跳过；
     `cellInfo.IsAvailable` 才扫 `ObjList`；`ActorObject` 且 `!Ghost`；
     `Race==Play` ⇒ 直接投递（**含自己**）；否则仅 `WantRefMsg` 且 `ident ∈ {RM_STRUCK,RM_HEAR,RM_DEATH}`；
   - 有 500ms 的 `VisibleHumanList` 缓存（`:395`），缓存命中时再按 `<11` 边界过滤（`:453-460`）。
   **合同**：宿主沿用 `broadcast_ref_msg` / `broadcast_ref_msg_with_self`，但需保证新实体刚入世界时缓存为空
   （测试里先 `world.tick()` 一次）。
2. `SendMsg(int ident, …)`（`BaseObject.Message.cs:34-96`）：投递到 **this 自己的队列**，`ActorId=this.ActorId`，
   无延迟。用于 `RM_MAKEHOLYSEIZEMODE`（`MagicManager.cs:1168` 的 `targetObject.SendMsg(...)`）。
3. `SendSelfDelayMsg`（`:188-206`）：投递到 **this 自己的队列**，`DeliveryTime=now+delay`、`LateDelivery=true`；
   `Ghost==true` 时不入队（`:190`）。`GetMessage`（`:334-355`）在未到点时重新入队（Lowest 优先级）。
4. `SendMsg(IActor baseObject, …)`（`:98-183`）：投递到 **this 的队列**，但 `ActorId=baseObject.ActorId`
   （处理时 `baseObject = ActorMgr.Get(processMsg.ActorId)`，`PlayObject.Message.cs:777`）。
   B3 只需要 `UseAmulet` 的 `SendMsg(playObject, RM_DURACHANGE, …)`（收件人是自己）。

## 3. 逐魔号合同

记号（与计划件一致）：`R(n)` = `Random(n)` 一次（`n==0` 也推进）；`GP13(n)` = `GetPower13(userMagic, n)`
（内含 1 次 `R(DefMaxPower-DefPower)`=`R(0)`）；`RP` = `GetRPow(WAbil.SC)`（`Hi>Lo` 时 1 次 `R(Hi-Lo+1)`，否则 0 次）；

`GetPower13(GetRPow(...)*2+30)` ⇒ **先 RP 后 GP13**。

> **跨魔号变体 F53-A（53 的 `ShowHp` 广播支，B3 判据）**：`B3Rig` + caster `show_hp=true`、其余同 F16-A，

### 4.2 路径 B：out-of-tree 的 .NET legacy `System.Random` 转录

按 .NET Framework 的 Knuth 减法滞后斐波那契（与 `mir2-shared::rng::DotNetRandom` 同一参考源）用 Python 独立实现，
**不调用任何 Rust 代码**；同一 max 序列输出与 §4.1 **逐项相同**（本件已跑）。

复算脚本（out-of-tree，`/e/tmp/b3rng/dotnet_random.py`，仅供复算，不入库）：

```python
MBIG = 2147483647; MSEED = 161803398
class DotNetRandom:
    def __init__(self, seed):
        a=[0]*56; sub = MBIG if seed==-2147483648 else abs(seed)
        mj = MSEED - sub; a[55]=mj; mk=1
        for i in range(1,55):
            ii=(21*i)%55; a[ii]=mk; mk=mj-mk
            if mk<0: mk+=MBIG
            mj=a[ii]
        for _ in range(4):
            for i in range(1,56):
                a[i]-=a[1+(i+30)%55]
                if a[i]<0: a[i]+=MBIG
        self.a=a; self.inext=0; self.inextp=21
    def sample(self):
        inext=self.inext+1; inextp=self.inextp+1
        if inext>=56: inext=1
        if inextp>=56: inextp=1
        r=self.a[inext]-self.a[inextp]
        if r==MBIG: r-=1
        if r<0: r+=MBIG
        self.a[inext]=r; self.inext=inext; self.inextp=inextp
        return r*(1.0/MBIG)
    def next_max(self,n): return int(self.sample()*n)
```

**契约**：实现卡至少跑通 A/B 两条；若真机窗口可用，再加路径 C（C# `System.Random(seed)` 反射探针，
`magic-effect-probe` 模式），三路必须一致。

### 4.3 帧序期望向量（`(ident, 收件人)`）

收件人记号：`SELF`=施法者 socket 911；`OBS`=玩家 2000 socket 912（±12 内）；`FAR`=玩家 3000 socket 914（±12 外）；
`NEAR(T)`=T 的 ±12 内玩家（T 为玩家时含 T）；`T`=目标 socket（若目标为玩家）。
