## 3. oracle 成色（哪些是「真身」，哪些是 source-cited）

**真身直调（探针实际调用 oracle 本体）**：

- `M2Server.Magic.MagicManager.IsWarrSkill(int)` —— `public static`（`MagicManager.cs:82-105`），
  对魔号 `0..=110` 全表实测。
- `M2Server.Magic.MagicBase.CheckAmulet(PlayObject, byte, byte, ref short)` —— `public static`
  （`MagicBase.cs:47-105`），用**真 `PlayObject`**（真 `UseItems[ArmRingl=5]/[Bujuk=9]`）+ 真
  `GameItemSystem`（`GetStdItem` 查表，`StdItem{StdMode,Shape}`）驱动；24 条场景矩阵。
- oracle 配置常量 `SystemShare.Config.MagicAttackRage`（= 8，`GameSvrConf.cs:1752`）与
  `MagicHitIntervalTime`（= 800）由探针读出写进向量头部。

**source-cited（`DoSpell` 内联语句/`switch` case 标签，无独立方法可反射）**：

- `spell_in_range` ← `MagicManager.cs:155`；
- `spell_version_gate` ← `MagicManager.cs:167`（`SoftVersionDateEx == 0 && ClientTick == 0 || MagicId > 80`）；
- `amulet_requirement` ← 6 个 `CheckAmulet` 调用点的 case 标签（`:229 / :323 / :452 / :464 / :620 / :908`）。

> 这三项在报告与 `magic.rs` 注释里都明确标了 **source-cited**，不冒充 oracle 向量；其语义由
> 「oracle 配置常量 + Rust 逐点断言」固定（`spell_in_range_uses_oracle_rage` / `spell_version_gate_source_cited`
> / `amulet_requirement_is_source_cited_table`），且需求表里每个 `(count,type)` 组合都必须落在探针矩阵
> 覆盖到的组合内（否则用例判红）。

## 4. 向量内容

- **战士技能**：oracle 判为 `true` 的魔号恰为 `{3,4,7,12,25,26,27,34,38}`（= `MagicConst` 的
  `SKILL_ONESWORD/ILKWANG/YEDO/ERGUM/BANWOL/FIRESWORD/MOOTEBO/CROSSMOON/TWINBLADE`），其余 102 个为 `false`。
- **护身符**：24 条场景，覆盖——
  - 槽位：`null` / `Index==0` / `ArmRingl(5)` / `Bujuk(9)`；优先级 `ArmRingl` 先于 `Bujuk`；
  - `StdMode != 25` 拒；`Shape`：type1 `==5`、type2 `<=2`，跨类型不匹配拒、未知 `nType=3` 拒；
  - 持久门：`Round(Dura/100.0) >= count`，含 `count=1`（50→命中 / 49→拒）、`count=2`（149→拒 / 150→命中）、
    `count=5`（449→拒 / 450→命中）；`Round` 为 `.NET MidpointRounding.AwayFromZero`（`hutil::round` 同式）。
- **护身符需求表**（source-cited）：`6→(1,2)`、`13..=19→(1,1)`、`30→(5,1)`、`41→(2,1)`、`36→(1,1)`、`48→(1,2)`。
