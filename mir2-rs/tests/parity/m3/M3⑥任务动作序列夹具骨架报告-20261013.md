## 2. 判据设计（对齐盘点报告 §4.1；**不放宽**）

逐 k（每次交互一行 `quest_raw.jsonl`）比较：

1. **op / npc / map / label**（选对动作、NPC、地图、脚本标签的直接证据）；
2. **req**（只比声明的稳定键 `item`/`n`；`npc_actor`/`make` 等动态 id **不作判据**，只留审计）；
3. **帧种类序列**（`sm` id 顺序）——接/交/条件判定的身份；
4. **`SM_MERCHANTSAY(643)` 说词逐字节**（脚本说词的直接证据；少一个空格都必须红）；
5. **声明的标量帧参数**（默认空；窗口期按真机实测补）；
6. **gold_before / gold_after**（原宽度整数，**不 i32 截断**，selftest 有 `i32-truncation-red` 钉住）；
7. **会话任务态位**：`quest_flag_before/after`（**必填**）+ `quest_unit_*`/`quest_open_*`（一侧有另一侧没有 ⇒ 判红）；
   按**规范化 hex 逐字节**比（`set [107] 1` ⇒ `QuestFlag[13] & 32`，selftest 有 `mutate-quest-flag-bit-red` 钉住；
   大小写不敏感）；
8. **branch**（`ok_say` / `ok_messagebox` / `fail_no_frame` / `frames_unclassified`）；
9. **bag 多重集**（`Counter` 计数式，**不做 set 差集**）。

**fail-closed**：缺文件 / 缺字段 / 类型错 / 非法 JSON / `k` 不连续 / op 非法 / frames 非数组 /
文本帧缺 `text` / **缺任务态字段或非法 hex** / `assemble` 有 send 无 end / `done.steps` 与 send 数不一致
⇒ **rc=2 PREREQ**，绝不静默 GREEN。

**改坏必红**：`selftest` 36 用例逐项改坏 op / npc / label / map / 帧种类 / 说词文本 / 帧标量 / price /
gold / bag / 任务态位 / 任务态存在性 / branch / 记录数；另在 `09-external-break-comparator-branch.txt`
里做了**外部改坏**——把比较器的 `branch` 比较删掉 ⇒ `selftest` 变 **35/36**（`mutate-branch-red` FAIL）、
rc=1；还原 ⇒ 36/36、rc=0（逐字节相同）。

### 2.1 两个必须处理的「状态/时序」坑（写进场景，窗口期验证）

- **任务态不落库**：oracle MySQL 本身不持久任务态（盘点报告 §1.F）⇒ 判据是「会话内任务态一致」+
  「DB 侧 `characters_quest` 两侧均 0 行、`characters` 无任务列变更」，**不是**「重登后标志仍在」。
  本夹具 DB 侧由 `scoped_diff.py --canonical --fixed-newchr` 判（`characters_quest` 已在作用域）。
- **`@Login` 会自动跑一批脚本**（真实 `QManage.txt` 的 `[@Login]` 调月卡/代练等）⇒ pin 后必须 settle 到
  `@Login` 完成；本场景的默认 case 不依赖 `@Login` 的副作用，且 pin 等级取 45（走 `checklevel 45`
  的 `#say` 分支）。窗口期按真机实测补 `frame_scalar_fields`。

### 2.2 任务态导出的接口（**本片只定契约，不造服务端 dump**）

BotSrv 客户端看不到任务数组（盘点报告 §4.1 第 2 条）⇒ `quest_diff.py assemble --state <file>` 接收
**服务端会话 dump**（每行 `{"k":N,"quest_flag_before":…,"quest_flag_after":…,…}`，hex 字符串）。
缺它 ⇒ `diff` 一律 PREREQ。该 dump 的生产面属 ⑥-3/⑥-4（`bins/game-svr` / `bins/db-srv` 写集），
本卡不越界；`run_quest_pair.ps1` 会在会话目录查找 `quest_state.jsonl` 并透传 `--state`。
