### 0.3 达成过程中发现并修复的 2 个真实前置缺陷

#### 缺陷 1（阻塞性）：Rust GameGate 起不来——`config.conf` 不是合法 UTF-8

症状：`start_rust_gates.ps1` 里 7200 起不来，`sessions/rust-gates/game-gate.err.log`：

```
Error: 读取配置文件失败：E:\MirServer\RunGate\config.conf（M1④：缺配置必须明确报错退出）
Caused by: stream did not contain valid UTF-8
```

根因：oracle `ConfigFile.Load()/Save()`（`src/OpenMir2/Common/ConfigFile.cs:258` / `:373`）
用 **`Encoding.GetEncoding("GB2312")`** 读写 `config.conf`；现网 `E:\MirServer\RunGate\config.conf`
（C# GameGate 启动时按 `Save()` 回写后）在 `[Strings]` 段**混有跨编码字节**（例：`Title=游戏网关`
是 UTF-8 字节，而 `HWIDBlockedMsg=...` 是 GBK 字节），**整体不是合法 UTF-8**。
Rust 侧 `bins/game-gate/src/config.rs` 用 `std::fs::read_to_string`（UTF-8）⇒ 直接失败、7200 顶不住。

修复（本批，`bins/game-gate/src/config.rs`）：按字节读 + `crate::gbk::decode`（cp936，同 oracle 口径；
本文件实际只消费 `[GameGate]/[Switch]/[Integer]` 纯 ASCII 键，解码口径改了也不影响这些键的判定），
并补一条「含 GBK 字节的现网同形配置仍能解析」单测。

> **跨车道提示**：`bins/game-gate/**` 属 `openmir2-m2-gamegate`（worker-10）的写集。本修复是为满足本卡
> 前置所做的**最小改动**，请按 §0b「同一文件一次只动一路」由 owner/协调者裁决归属与复核。

#### 缺陷 2：`run_m3_gate.ps1` 第 3 步跨侧比对从未真正跑通（路径取错）

症状：第一次 `-Side rust` 到第 3 步就 `FileNotFoundError: 'rust-20261011-143315\scoped_after_norm.jsonl'`。
根因：`$sessionDir` 是 `DirectoryInfo`，`Join-Path $sessionDir 'scoped_after_norm.jsonl'` 调 `ToString()`
只得到**目录名**（相对路径）⇒ 比较器在仓库根找文件必然找不到。此前该步从未被执行（一直无 peer），故一直潜伏。

修复（本批，`run_m3_gate.ps1`）：用 `$sessionDir.FullName` 拼绝对路径；并给候选会话目录加
`baseline.json` 存在性过滤（避免 `sessions/rust-gates/` 这类非会话目录被 `rust-*` 通配命中）。
修复前的 RED 报告（`M3-gate-rust-20261011-143312.json`，`failed=[cross_side_diff_nonzero]`）保留为缺陷证据；
注意那次 run_pair 本身是成功的、其作用域行手工重比也是 GREEN。

| | 5,6,9 | 3 个 datetime | `2026-10-10 08:47:42` → `2026-10-11 03:08:38` | 墙钟 |

### 2.3 根因（更硬的一条）：假人建角时 **职业随机**，两侧根本不是同一个输入

`src/BotSrv/Scenes/Scene/SelectChrScene.cs:154-176`（只读取证，红线段未改）：

```csharp
byte sHair = 0;
switch (RandomNumber.GetInstance().Random(1)) { ... }   // :157 发颜色随机
byte sJob  = (byte)RandomNumber.GetInstance().Random(2); // :174 职业随机 (0/1)
byte sSex  = (byte)RandomNumber.GetInstance().Random(1); // :175 性别随机
SendNewChr(RobotClient.LoginId, sChrName, sHair, sJob, sSex);
```

`RandomNumber.GetInstance()` 内部是 `new Random()`（无种子，时间驱动；`src/OpenMir2/RandomNumber.cs:20-38`）
⇒ **每次运行的建角输入不同**。跨侧对拍的前提是"同序列"，而这一格从一开始就不是同序列，
拿它做 diff 只能得到噪声。
