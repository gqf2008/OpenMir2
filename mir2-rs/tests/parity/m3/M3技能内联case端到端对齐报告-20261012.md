## 2. oracle 事实（逐行核过，含行号自检）

1. **40 `SKILL_UNAMYOUNSUL`（`MagicManager.cs:495-523`，内联效果）**：
   `targetObject == null` ⇒ 取自身（`:496-501`）；`IsProperFriend(targetObject)`（`:502`，新构造 `PlayObject` 的
   `AttatckMode` 默认为 `HAM_ALL=0` ⇒ 对 Play 目标恒真）；
   `M2Share.RandomNumber.Random(7) - (userMagic.Level + 1) < 0`（`:504`）才清三态：
   `StatusTimeArr[DECHEALTH/DAMAGEARMOR/STONE] != 0` ⇒ 置 `1` 并 `boTrain = true`（`:506-520`）；
   `:523 break`。⇒ **该 case 会抽一次 `Random(7)`；命中后因 `boTrain` 还会走共享尾的训练门抽 `Random(3)`**。
2. **43 `SKILL_43`（`:555-556`）**：`case MagicConst.SKILL_43: break;` ⇒ **连 `boTrain` 都不置**，唯一运行时可观测行为是共享尾的 `:648 RM_MAGICFIRE`。
3. **49/51/52/53/54（`:607-642`）**：case 体只置 `boTrain = true` ⇒ 唯一效果是共享训练尾。
4. **共享尾（`:644-670`）取数顺序**：先判 `:659 userMagic.Level < 3 && boTrain`、再判 `:661 TrainLevel[Level] <= Abil.Level`，**两者都过才**在 `:663` 抽 `M2Share.RandomNumber.Random(3) + 1` 并 `TrainSkill`（第九片已 vector 化该段）。
5. **锚点自检**：探针内置 `VerifyAnchors`，逐条读 oracle 源断言 28 个锚点（条数已机器断言，见 §8）
   （`MagicManager.cs:82/145/151/167/172/495/502/504/506/511/516/523/555/556/607/631/634/637/640/648/659/661/663/670`；
   `PlayObject.Base.cs:1369/1505/1512/1522`），任一不符**直接终止探针**（不出带错行号的向量）——
   与第七/八/十片同一防行号漂移机制。

  `RecordingRandom(seed)`，按 `ReplayRandom` 行式格式 `seq|kind|arg|result|site` 记账。

  （`PlayObject.cs:993 FixedHideMode=true`）⇒ `SendRefMsg` 走 `BaseObject.Message.cs:390` 自身分支，
  帧落自身 `MsgQueue`（帧 ident/参数是 oracle 原值）。

  探针把 `ActorId` 钉为 `910040`，使向量逐字节确定（连跑 2 次 JSON/TSV 完全一致，见 §5）。
