## 2. Rust 实现（写集：`crates/envir` + 只读消费 `crates/script`）

- `crates/envir/src/merchant.rs`（新）：
  - `MerchantRecord`：10 个配置列 + `flags`/`price_rate`/`item_type_list`/`refill_goods`；
  - `parse_merchant_line(&str) -> Option<MerchantRecord>`：单行解析（脚本头字段默认）；
  - `MapLoader::merchant_path()` / `load_merchants(&mut rename_rand)`：整文件加载 + 逐条脚本头 / `[goods]` 装配。
- `crates/envir/src/error.rs`：新增 `EnvirError::MerchantScriptLoad`（脚本 `LoadPanic` 穿透）。
- `crates/envir/src/lib.rs`：模块声明 + 重导出。
- `crates/envir/Cargo.toml`：新增 `mir2-script` 依赖（`crates/script` 仅依赖 `mir2-shared`，无环）。
- **复用而非重写**：脚本头 / `[goods]` 的解析器（含 `%PRICERATE>=55`、`GetValidStrCap`、`ArrestStringEx`、
  重名 label 改名）全部来自 `crates/script`；本模块只做「逐条取脚本 → 把头 4 个字段搬到记录上」。
- **有效价倍率**：`outcome.price_rate.unwrap_or(100)`（`None`/缺失/`<55` ⇒ 构造默认 100）。
- **`CanSellItem` 常量 true** ⇒ `[goods]` 不做额外过滤，与解析器的 `refill_goods` 一致（已登记，见 §5）。

### 两条**刻意保留的 oracle 语义**（硬约束③：行为等价优先于修 bug，不顺手「修好」）

1. **`%PRICERATE < 55` 不生效**（`ScriptParsers.cs:687`）：部署件有 5 处以 `%20` 声明，oracle 一律忽略
   ⇒ 本模块的 `price_rate` 保持 100。牙齿见 §3-A。
2. **`BoCanMove` 必须 `MoveTime > 0`**（`LocalDB.cs:465`）：只填 `CanMove=1` 而 `MoveTime=0` 仍不可移动。
   牙齿见 §3-B。
