```rust

    .entities
    .get(group_owner)
```

改为 fail-closed：

```rust
// oracle `PlayObject.Base.cs:771-776`：`GroupOwner != 0` 时先
// `(IPlayerActor)SystemShare.ActorMgr.Get(GroupOwner)` 取团长对象；取不到
// ⇒ `groupOwnerPlay.GroupMembers` 空引用抛异常，被 818-821 的 `catch` 吞掉

```

要点：
- 团长不在注册表 ⇒ **不授奖**（`record.exp_awards` 不追加）、返回 0（**不退回单人满经验**），

- 团长在场分支与 `group_owner == 0` 分支**逐字节不变**（含 `|CurrX-x|` 两处都漏 `CurrY`
  的 oracle 既有缺陷照搬，§1 硬约束③）；
- 遍历/取数顺序不变（成员表序），零并行、零 RNG 消费，tick 顺序确定；
- 函数文档补一条缺团长态语义并修正 oracle 行号 `764-818` → `764-821`（`catch` 到 `:821`）。
