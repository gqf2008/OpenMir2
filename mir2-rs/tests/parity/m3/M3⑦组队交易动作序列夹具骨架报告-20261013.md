## 0. 一句话

组队/交易在 oracle 里都是**会话内内存状态机、不落库**（盘点报告 §0/§1.M）⇒ 判据 = **帧证据 + 金币/背包副作用**
（+ 归属/分配扩展位），不判「重登后状态仍在」。本片把这条判据做成**可离线复跑**的机器件：
`party_trade_diff.py`（逐 (bot,k) fail-closed 比较器，selftest 27/27）+ `run_party_trade_pair.ps1`
（`-SelfCheckNoStack` 19/19）+ BotSrv 最小驱动（`--selftest-pairtrade` 29/29，默认关逐字节不变）+
`party_trade_scenario.json`（3 个 case）。**真机跑仍 fail-closed**（未给 `-Go` / Rust 侧未接线 ⇒ exit 2）。

## 2. 本片交付（写集 = `mir2-rs/tests/parity/m3/**` + `src/BotSrv/**` + `tools/botload/run_bots.ps1` + `whitelist.md`）

### 2.1 比较器 `party_trade_diff.py`（判据本体）

- **记录 schema**：`{bot, k, role, op, ran, param, frames[], gold_before/after, bag_before/after, exp_before/after, level_before/after, pickup_ok, branch}`
  （`bot` = `ChrName` = `LoginAccount+序号`；每 bot 内 `k` 必须 0 起连续）。
- **`assemble`**：`M3PAIRTRADESEQ {json}` 事件流（arm/send/frame/end/done）→ 按 `(bot,k)` 合并记录；
  缺 `end` / `done.steps` 与 send 数不一致 / 无事件 ⇒ **PREREQ（rc=2）**，不静默。
- **`diff`**：逐 `(bot,k)` 比 `op/role/ran/param/帧种类序列(严格顺序)/文本帧逐字节(SM_GROUPMESSAGE 101)/
  声明标量帧参数/金币原宽度/背包多重集/exp·level·pickup(Counter 与一侧有无)/branch`；
  **两侧 bot 集合必须相同、每 bot 的 k 集合必须相同**（= §6「两人及以上」的机器化落点）。
- **`selftest` 27/27**：identical-green + 逐字段改坏必红（op/param/branch/role/ran/gold/帧 sm/帧标量/文本/exp/
  pickup/bot 集合/记录数）+ 多重集次序绿/count 红 + fail-closed（k 断档、缺文本、帧 sm 非整、非法 op、
  非法 JSON、缺文件、assemble 的 done 不一致/有 send 无 end/无事件）。
- **口径登记**：`branch` 只作粗归类（`ok` / `fail_reject` / `skip_other_role` / `fail_no_frame` / `frames_unclassified`），
  具体失败码由**完整 sm 序列 + 声明标量**承载——**不用 JSON 子串硬匹配字段**（吸收 ⑤-6 reviewer M-1 的教训）。

### 2.2 入口 `run_party_trade_pair.ps1`

- 复用 `run_pair.ps1`（两相 pin + `-StopAfterCharCreated` 预热 + 收尾 save-settle 仪器）；两假人相邻 pin
  复用 `-PinStartPose -AttackPinPair`（actor `(17,20) dir=2`、peer 右邻 `(18,20)`；R-1 零 AI 消费者图 `0137`）。
- `M3PAIRTRADESEQ` 完整性机判：**两个假人各自**的 `arm` + 每个 step 的 `send`/`end` + `done`；缺任一段 ⇒ **RED**。
- 跨侧两道判据：`party_trade_diff.py diff`（逐 (bot,k)）+ `scoped_diff.py diff --canonical --fixed-newchr`
  （组队/交易态不落库口径）。
- `-SelfCheckNoStack` **19/19**；未给 `-Go` ⇒ real-run **fail-closed（exit 2）**；`-Side rust` preflight
  （game-svr 无组队/交易常量）⇒ **PREREQ（exit 2）**，不白占窗口。
