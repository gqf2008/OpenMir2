## 0. 一句话结论

**Rust `combat.rs:831` 的 `AttackSuccess` 与 oracle 同形（只属玩家攻方、有目标即恰 1 抽），不是实现缺陷；
owner 看到的「C# `hit_gate` 19 → `attack_success` 3」是把 16 个非玩家 base 单元的门算进了玩家门
—— 玩家门恰为 3 = `attack_success`。第一处请求分歧（index=2）也已定位到 base 单元（非玩家路径）。
真正两侧不同的是「玩家攻方有目标的击数」（C# 3/120 vs Rust 38/120），其停机点已钉在目标解析层。**

## 2. ② 「`hit_gate` 19 → `attack_success` 3」的正确读法

`C#` 专用流按 `atk_power_*` 切单元：**base（非玩家攻方）16 个、player 120 个**（`08-base-unit-attribution.txt`）。

| 站点 | C# 总 | base 单元 | player 单元 | Rust |
|---|---|---|---|---|
| `atk_power_base` / `atk_power_a` | 16 / 120 | 16 | 120 | 0 / 120 |
| `hit_gate` | 19 | **16** | **3** | 38 |
| `attack_success` | 3 | 0 | **3** | 38 |
| `hit_struck_damage`(+2) | 17(+4) | 16(+4) | 1(+0) | 19(+0) |
| `struck_durability` | 1 | 0 | 1 | 19 |

⇒ 玩家门(3) == `attack_success`(3)。**两侧 `AttackSuccess` 调用关系同形**；真正不同的是
**「玩家有目标的击数」C# 3 vs Rust 38**（`05-target-availability.txt`：C# 目标只在 k=1..3；Rust k=1..38）。

**停机点（oracle 行号）**：C# k>=4 无任何玩家门/`succ` 抽 ⇒ `targetObject ?? GetPoseCreate()`
（`PlayObject.Attack.cs:26`）返回 `null` ⇒ `_Attack`（`BaseObject.Attack.cs:32`）与 `AttackSuccess`
（`:217`）都提前返回。**不是**拒绝门（120 条 `CM_HIT` 全进 `AttackDir`，`atk_power_a/b` 各 120）、
**不是**目标死亡（cA `death_k=None`、`min_hp=18`）、**不是**掉线（RunGate 两连接直到 21:57:44 才断开）。
⇒ 目标格（18,20）在 k=4 起为空。其成因属夹具/场景（转 m3bag：建议逐 k 记 victim `CurrX/CurrY + Ghost/Death`）。

## 3. ③ 每击取数请求序列：第一处分歧定位

机判工具 `per_strike_requests.py`（selftest 8/8；玩家路径多抽/次序/单元数不等必红；base 单元归
`base_unit` 不误判）。`(kind,arg)` 逐次比分（与 `compare_dedicated_streams.py` 同口径）：

```
#1  C# atk_power_base(Next(max),1)   | Rust atk_power_a(Next(max),1)      <- 请求完全相同（都 Random(1)）
#2  C# hit_gate(Next(max),8)         | Rust atk_power_b(Next(max),10)     <- **第一处分歧 index=2（1-based）**
```

- C# 流首是**非玩家 base 单元**（`BaseObject.GetAttackPower@BaseObject.Base.cs:892`），其首抽与 Rust 首个
  玩家抽**请求相同** ⇒ 第 1 次不比出差异；第 2 次 base 单元的门显形 ⇒ **class = base_unit**。
- **玩家路径内无分歧**：两侧各 120 个 player 单元，取数模板（躲闪 `a,b,gate,succ` / 命中
  `a,b,gate,[hsd2,]hsd,durab,succ`）**0 违规**（`02/03-analyze-*`）。C# 玩家单位模板同形，
  只是**值被 base 单元推移**（如 k=1 门 draw C#=10 躲闪、Rust=4 命中），因此逐击命中/伤害自然不同。

## 4. ④ 因果登记（只登记，不修）

  （cA/rA 真机读数一致）。这确实把「有目标窗口」压短（Rust k=38 目标 HP 归零后即无目标），
  **但 C# 停在 k=4 时 `min_hp=18`、未死** ⇒ ④ **不是** C# 3/120 的直接成因。④ 本体归 m3bag。
