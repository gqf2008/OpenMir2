-- 关键语义：C# 是 **int 减法，差量可负** --
- :1101 与 :1111 的被减数 = Grobal2.MaxBagItem（clamp 常量；本仓 = 46），减数 = ItemList.Count（背包件数）。
- 正常流程容量门保证 ItemList.Count <= MaxBagItem；但**该表达式的类型是 int，不钳位**：
  一旦 ItemList.Count > MaxBagItem（异常/被构造的状态），差量为负，`-1 < DealItemList.Count`
  对任意 Count >= 0 恒为真 ⇒ oracle **拒结算**（YourBagSizeTooSmall / DealHumanBagSizeTooSmall）。
- Rust 侧旧实现用 `usize::saturating_sub`（`0` 下限）⇒ `0 < 0` 为假 ⇒ 在「超容量 + 对方交易栏为空」
  时把 oracle 的拒绝改成了**放行结算**（reviewer-6 fbb382aa056a M-3）。
