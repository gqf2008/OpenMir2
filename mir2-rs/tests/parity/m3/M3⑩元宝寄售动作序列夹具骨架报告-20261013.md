## 0. 一句话

元宝寄售在 oracle 里是**进程级内存列表**（`M2Share.SellOffItemList`）+ 金额副作用（`GameGold`/`Gold`），
**不落库**（`SaveSellOffItemList` 调用点全注释、读列名写错 D-5/B-5 ⇒ 两侧都恒加载 0 行、都永不写）⇒
判据 = **帧证据 + 元宝/金币/背包副作用**（+ DB 增量 = 0）。本片把这条判据做成**可离线复跑**的机器件：
`selloff_diff.py`（逐 (bot,k) fail-closed 比较器，selftest 33/33）+ `run_selloff_pair.ps1`
（`-SelfCheckNoStack` 19/19）+ BotSrv 最小驱动（`--selftest-selloff` 29/29，默认关逐字节不变）+
`selloff_scenario.json`（5 个 case）。**真机跑仍 fail-closed**（未给 `-Go` / Rust 侧未接线 ⇒ exit 2）。

## 2. 本片交付（写集 = `mir2-rs/tests/parity/m3/**` + `src/BotSrv/**` + `tools/botload/run_bots.ps1` + `whitelist.md`）

### 2.1 比较器 `selloff_diff.py`（判据本体）

- **记录 schema**：`{bot, k, role, op, ran, param, frames[], gamegold_before/after, gold_before/after, bag_before/after, branch}`
  （`bot` = `ChrName` = `LoginAccount+序号`；每 bot 内 `k` 必须 0 起连续）。
- **`assemble`**：`M3SELLOFFSEQ {json}` 事件流（arm/send/frame/end/done）→ 按 `(bot,k)` 合并；
  缺 `end` / `done.steps` 与 send 数不一致 / 无事件 ⇒ **PREREQ（rc=2）**，不静默；非 JSON 的 `skip=` 行只当结构化 warning。
- **`diff`**：逐 `(bot,k)` 比 `op/role/ran/param/帧种类序列(严格顺序)/文本帧逐字节(SM_MENU_OK 767)/
  声明标量帧参数/元宝原宽度/金币原宽度/背包多重集/branch`；两侧 bot 集合必须相同、每 bot 的 k 集合必须相同。
- **`selftest` 33/33**：identical-green + 逐字段改坏必红（op/role/ran/param/branch/元宝/金币/背包/帧 sm/帧文本）+
  多重集次序绿/count 红 + 帧标量 + 帧顺序 + bot 集合/记录数 + fail-closed（k 断档、缺文本、帧 sm 非整、非法 op、
  非法 JSON、缺文件、assemble 的 done 不一致/有 send 无 end/无事件/未知 phase）。

### 2.2 入口 `run_selloff_pair.ps1`

- 复用 `run_pair.ps1`（两相 pin + `-StopAfterCharCreated` 预热 + 收尾 save-settle 仪器）；两假人相邻 pin
  复用 `-PinStartPose -AttackPinPair`（卖方 `(17,20) dir=2`、买方右邻 `(18,20)`；零 AI 消费者图 `0137`）。
- `M3SELLOFFSEQ` 完整性机判：**两个假人各自**的 `arm` + 每个 step 的 `send`/`end` + `done`；缺任一段 ⇒ **RED**。
- 跨侧两道判据：`selloff_diff.py diff`（逐 (bot,k)）+ `scoped_diff.py diff --canonical --fixed-newchr`（寄售态不落库口径）。
- `-SelfCheckNoStack` **19/19**；未给 `-Go` ⇒ real-run **fail-closed（exit 2）**；`-Side rust` preflight
  （game-svr 无元宝寄售常量）⇒ **PREREQ（exit 2）**，不白占窗口。
