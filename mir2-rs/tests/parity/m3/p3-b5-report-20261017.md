## 1. 结论摘要

1. **四魔号按 oracle 魔号分派落地**：9/10 走 `MagPassThroughMagic`（步长 5/8、≤12 格、
   `R(10) >= AntiMagic`、600ms `RM_MAGSTRUCK`）；10 的 `undeadAttack` 对**每个命中**无条件
   `Round(magPwr*1.5)` 且**逐击复合**；22 先求值 5–6 抽再判安全区、5 格固定顺序、
   `MagMakeFireCross` 恒 true；36 先 `IsProperFriend` 再 `CheckAmulet`/`UseAmulet`，
   抽数 `R(Level)`（Level=0 也推进）→ `GP13` → `AP`，`AttPowerUp` 写 `ExtraAbil[0]` 并全量 recalc。
2. **32 的同族组队门收口**：外层 `IsProperTarget` 改用
   `World::attacker_group_members`（读**团长**成员表，而非施法者自己的空表）。
3. **帧序按每收件人 `.NET PriorityQueue` 出队序**：`SpellFrameBuf` 按 `(byte)RM_*` 稳定升序
   （52=67 → 53=68 → 638=136 → 639=137 → 642=141 → 100=252 → 640=255）。
   **`SM_SPELL(17)` 的线上帧被 `RM_SPELL` 自守卫（`PlayObject.Message.cs:1455`）吞掉**，
   但队列项仍存在——所以 caster 的**可观测**线上序从 53 起；观察者/目标仍收 17。
4. **BUG-REPLICA 三件套照搬**：`MapEvent.Id` 恒 0 / `CellObjectMgr.TryAdd(0, …)` 第一条胜 /
   越界格事件仍进全局表；`FireBurnEvent` 首次 Run 用进程 uptime 门（初值 0）。
5. **牙 15 条全部 RED**（9：4、10：3、22：3、36：5），还原后 4 条 B5 用例全绿。

## 3. 逐魔号实现要点

### 3.1 9 / 10 穿透（`cast_pass_through_spell`）

- `GetNextPosition(CurrX,CurrY,nextDir,1)` 失败 ⇒ **零抽、无效果体**；共享尾仍用点击坐标发 638。
- 终点 `GetNextPosition(CurrX,CurrY,nextDir,steps)`（9=5 / 10=8；未变时 = 施法者坐标）。
- `nPower = GetAttackPower(GetPower(MPow)+Lo(MC), ΔMC+1)`（4 抽；`AttackPowerMode::for_attacker`）。
- 循环 `i<12`：`GetMovingObject(sx,sy,true)`（格 `ObjList` 插入序、`!Ghost && !Death`）→
  `IsProperTarget` → `R(10) >= AntiMagic` →（10）`Round(magPwr*1.5)` → `SendStruckDelayMsg(...,600)`。
- 终止：到终点即 break；`GetNextPosition(...,1)` 未变即 break。

### 3.2 22 火墙（`cast_fire_wall_spell` + `run_map_events`）

- C# 实参先求值：`power_fire_wall`（4 抽）→ `GetPower(10)`（1 抽，`R(0)`）→ `GetRPow(MC)`（0/1 抽）。
- 安全区门 `DisableInSafeZoneFireCross && caster.in_safe_zone` ⇒ `safe_zone_blocked`（调用方发 100），
  事件零落地，`boTrain=false`。
- 5 格固定顺序 上/左/中/右/下，`event_at == None` 才建；`boTrain` 恒 true。
- `event_at` = 「格内有 `CellType::Event` 对象」**且** `event_registered`（管理器 id=0 第一条胜）。
- `run_map_events`：逆插入序、`Active && now-RunStart > 500`；`FireRunTick` 初 0 ⇒ uptime>3000 时
  首次 Run 就结算；`RM_MAGSTRUCK_MINE` 入 `pending_mag_struck{ mine: true }`（投递只抽 MSD，无 `R(1000)`）；
  关闭门 `now-OpenStart > ContinueTime`（严格大于）。

### 3.3 36 无极真气

- 目标归一（null ⇒ 自己）→ `IsProperFriend`（玩家施法者只放行 `Race==Play`）→
  `CheckAmulet(1,1)`（**ArmRingl 命中即返回**）→ `UseAmulet`（Dura>100 ⇒ 642；否则删除物品 202 + 清槽）
  → `R(Level)`（Level=0 也推进）→ `GP13(60)` → `AP` → `AttPowerUp`。
- `AttPowerUp`：`ExtraAbil[0]=nPower`、`ExtraAbilTimes[0]=now+nTime*1000`、`SysMsg(Green)`
  → `RecalcAbilitys()`（**全量** `recalc_session_ability` + `apply_extra_abil`）→ `RM_ABILITY(52)`。
- 52 的 WAbil 尾 = 重算后的整个 `WAbil`（生产默认 58B 客户端布局；`ability_tail` 按环境切换）。
- 防御臂：`(IPlayerActor)` 强转失败 ⇒ 639、无尾（当前玩家入口不可达；仍显式建模）。

### 3.4 32 同族组队门

`SKILL_KILLUNDEAD` 外层 `IsProperTarget` 改读 `World::attacker_group_members`。
真实 party 布局（团长持表、成员只有 `group_owner`）下，成员施法对同组玩家 ⇒ 非 proper ⇒
零抽 + 共享尾 638（无 640）；改回施法者自己的空表 ⇒ proper ⇒ `InvalidCast` 防御臂 639（牙可判别）。

## 7. 已知偏差 / 未决项（登记，不忽略）

1. **T-75**：22 的 `InSafeZone` 只建模第 1 步（`Entity::in_safe_zone`）；`RedHome*` 与 `StartPointList`
   两步未装载。部署 `DisableInSafeZoneFireCross=1`；构造级用 `in_safe_zone` 覆盖。
2. **T-76**：`ExtraAbil` 过期检查节拍 = 每 world tick（200ms），oracle 是每 `PlayObject.Run` 消息泵；
   只有相位差、无 RNG。
3. **T-77**：`RM_MAGSTRUCK(_MINE)` 的 `FastParalysis` 支恒 false（本骨架无该状态写者）。
4. **`is_proper_target_grouped_direct` 与折入版的差异**：折入版（既有攻击调用点）检查
   `target.invisible`；oracle `PlayObject.IsProperTarget` 不检查可见性。B5 的范围魔法/事件改用
   direct 版（枚举面已过滤 Death/Ghost），行为与 oracle 对齐；既有调用点不动（登记为同族已知口径）。
5. **`Random(0)` 语义**：本仓 `next_max(0)` 仍调用 `sample()` 推进一条样本（合同 §8-6 口径）；
   若 .NET 真机不同，全部账本需重写（真机窗口项）。
6. **同优先级队列**：`.NET PriorityQueue` 同优先级无 FIFO 保证；B5 的帧集合内同优先级最多一条
   （或按插入序），判据只依赖不同优先级相对序。
7. **36 的 52 客户端布局**：生产默认 58B `TAbility`（`MIR2_CLIENT_ABILITY_LAYOUT` 未设）；
   oracle 40B 支由 `ability_tail` 的既有单测钉住。测试比较 `ability_tail(..., client_layout_enabled())`。
8. **真机窗口**：R 级要求真机全量对拍（RNG 流水 + 600ms 投递 + 事件 500/3000ms 门 + 52/100 帧字节）。
   本片只完成构造级；`review` 须写 `"window_required": true`。
9. **事件处理器周期（非阻塞，登记）**：world tick = **200ms**，oracle `EventProcessor` 定时器 = **20ms**
   （`EventProcessor.cs:27-60`）⇒ 事件 `Run` 的落点有 ≤180ms 相位差。构造例在 `run_events(600)` 才看到
   首次伤害（oracle 约 +520ms）。只影响相位，**不改变**每次 `Run` 的取数次序与条数（RNG 账本不变）。
10. **`event_at` 的 `first_registered` 语义（must-fix 已收口）**：原实现返回全局表 `first()`；
    已改为返回**第一条 `registered == true` 且同图**的事件（复刻 `CellObjectMgr.TryAdd(0, …)` 第一条胜）。
    仅「首建事件格非法 + 后续注册」可观测，构造级不可见；改动本身无 RNG/帧面影响。
