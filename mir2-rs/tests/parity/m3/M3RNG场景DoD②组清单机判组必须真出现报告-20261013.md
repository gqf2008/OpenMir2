## 1. 缺口：DoD② 的「三组两侧都出现」无人校验（可复现假绿）

卡 DoD② 要求 `monster_ai` / `spawn` / `drop` **两侧都出现**；`rng_trace_scenario.json` 也声明了
`trace.groups_expected` 与 `trace.min_monster_ai_draws`。但合并后的工具：

- `rng_scene_gate.py::scenario_trace_checks` 只校验 `groups_expected` 的**组名在册**；
- `rng_ledger_diff.py::cmd_groupdiff` 的 `GROUP_SET_DIFF` 只比**两侧彼此相等**；
- `min_monster_ai_draws` 全仓无引用。

⇒ 两侧流水都只含 `spawn`（`monster_ai`/`drop` 两侧都缺）时，组集合彼此相等 ⇒ `VERDICT IDENTICAL`
+ gate GREEN（证据 `01`；对照 `04`：旧工具根本没有 `--scenario` 选项）。这正是 owner 禁的
「只写白名单不校验」。

## 2. 修复

`rng_ledger_diff.py::cmd_groupdiff --scenario <path>` 把声明与**真实账本**对账：

| 声明 | 不满足 | flag / rc |
|---|---|---|
| `trace.groups_expected` | 任一侧缺组 | `MISSING_EXPECTED_GROUPS`（点名组 + side）/ rc=1 |
| `trace.min_monster_ai_draws`（或 `trace.min_group_draws`） | 任一侧抽数不足 | `MIN_GROUP_DRAWS`（`want`/`a`/`b`）/ rc=1 |
| — | scenario 不存在 / 坏 JSON / 未知组 | PREREQ rc=2 |

- `run_rng_trace_pair.ps1 -SceneGroupDiff` 自动把同一 scenario 传给 `groupdiff`（单一入口
  同时覆盖 DoD① 场景门与 DoD② 组清单）；`-GroupDiffOnly`（裸比较）不传 ⇒ 缺省行为逐字节不变。
- `rng_trace_scenario.json` 的 `trace.criterion` / `artifact.groupdiff` / `notes` 同步写明该机判。
