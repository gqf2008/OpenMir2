# M2 世界模拟骨架 —— 交付报告（D 线 worker-4）

卡片：`openmir2-m2-world-kickoff`。worktree `worktree-m2-world`。
基准：`src/GameSvr/Word/WorldServer.cs::ProcessHumans`（200ms 节拍）、
`src/M2Server/Maps/Envirnoment.cs`、`src/M2Server/Actor/BaseObject.ViewRange.cs`。
范围：**不依赖 M1** 的部分（tick/实体/地图/AOI/会话进出）；边界服务一律未做。

## 四条判据 → 证据

### ① tick 顺序与 AOI 边界的单测（可证伪）

命令：`cargo test -p mir2-world`（12 条）+ `cargo test -p mir2-parity-tests --test world_aoi_parity`（3 条）

| 测试 | 钉住的语义 |
| --- | --- |
| `tick_advances_clock_by_200ms` | 节拍 = 200ms（`WorldServer.cs:487`） |
| `tick_order_is_deterministic_and_documented` | 命令 FIFO；AOI 按槽位顺序；同操作 → 同顺序 |
| `aoi_boundary_at_view_range` | dx=ViewRange 可见、+1 不可见（闭区间） |
| `aoi_scan_order_is_x_outer_y_inner` | X 外层/Y 内层升序；自己先入列（无自排除） |
| `tick_refuses_to_run_on_another_thread` | 换线程 tick ⇒ panic |
| `session_enter_leave_world` | 进图有格子、离开清格子并移除实体 |
| `redcheck_view_range_change_must_alter_visible_set` | 改视野 +3 ⇒ 可见集必变（判据非恒真） |
| `redcheck_position_change_must_differ` | 改坐标 ⇒ 首行必变 |
| `column_major_indexing` / `get_cell_info_returns_cell0_on_failure` / `move_blocked_by_any_actor_in_target_cell` / `move_ignores_block_when_flag_set` | 列主序 `x*Height+y`；失败返回 `CellArray[0]`（C# 怪癖照抄）；阻挡与 `boFlag` |

### ② 同地图同实体 N tick 后位置/可见集与 C# 逐项相同

- 夹具：`tests/parity/csharp/WorldGolden`（`SearchViewRange` / `SearchViewRangeDeath` /
  `UpdateVisibleGay` / `GetCellInfo` / `AddMapObject` / `MoveToMovingObject` **逐字拷贝** + 虚拟时钟）
- 命令：`dotnet run --project .../WorldGolden -c Release -- basic` →
  `cargo test -p mir2-parity-tests --test world_aoi_parity`
- 结果：**14 实体 × 10 tick，位置与可见集逐行一致（含列表顺序）**；两条红检自动跑（改视野/改坐标必红）
- 对齐过程确认的行为：**C# 的 AOI 不排除观察者自己**（金标准里 `ent 1 30 30 vis 1:2 …`）——照抄不修

### ③ 禁止引入并行（断言保护）

- 依赖白名单：`crates/world` 只许依赖 `mir2-shared`，禁用 tokio/rayon/crossbeam/futures/actix/kameo 等
  （`crates/world/tests/no_parallel.rs`；含"注入 rayon 必被识别"的红检）
- 运行期：`World::tick` 每次校验线程 id，换线程即 panic
- 覆盖边界（诚实声明）：拦的是"依赖/驱动方式引入并行"；若外部自行 spawn 线程但以单线程方式驱动本 world，
  内部仍串行（符合 §4.2）

### ④ 单线程 tick P99 基线（供 M5）

命令：`cargo run -p mir2-world --release --bin tick_bench -- 500 2000 1000 2000 2000 1000`
（实体铺在 200×200 地图、间隔 2 格、每 tick 1/4 实体走一步、固定种子 42）

| 实体数 | tick 数 | P50 | P90 | P99 | max | P99/200ms 预算 |
| --- | --- | --- | --- | --- | --- | --- |
| 500 | 2000 | 428µs | 565µs | **669µs** | 948µs | 0.33% |
| 1000 | 2000 | 1142µs | 1388µs | **1818µs** | 3324µs | 0.91% |
| 2000 | 1000 | 3017µs | 3461µs | **3963µs** | 6587µs | 1.98% |

**修复前/后（同一命令，已定位并修掉的真问题）**：初版实体查找是线性扫（`find_map`），
AOI 过滤器每次命中都 O(N) ⇒ 单 tick 近似 O(N²)：

| 实体数 | 修复前 P99 | 修复后 P99 | 倍数 |
| --- | --- | --- | --- |
| 500 | 3173µs | 669µs | 4.7× |
| 1000 | 17262µs | 1818µs | 9.5× |
| 2000 | 80219µs | 3963µs | 20.2× |

改动：`EntityStore` 增加 `id → 槽位` 索引（O(1) 查表，对齐 C# `ActorMgr.Get` 的字典语义）。
该索引**只用于查表、不参与遍历**，故 tick 的确定性顺序不变（遍历恒为槽位顺序）。

# M2 下半程（最小切片）：会话进世界 + 掉落系统（卡片 openmir2-m2b-world-session）

范围（按 owner 指令刻意收窄到"最小切片 = 会话 + 一个系统"）：
**会话进世界**（进图/切图/掉线/小退/再进）+ **掉落系统**（生成时预算 RNG、死亡时落地）。
**不在本切片**：战斗结算进 golden（`_Attack` 的 RNG 面）、经验结算进 golden、技能。

## 判据 → 证据

| 判据 | 结果 |
| --- | --- |
| world 层测试全绿 | `cargo test -p mir2-world` **15 条**（会话状态机/切图/小退再进、攻击结算可复现、死亡掉落+经验只结算一次、攻击目标子集、tick 顺序与 AOI 边界、禁并行 3 条） |
| 扩展场景与 C# 逐行一致 | `cargo test -p mir2-parity-tests --test world_session_parity`：`session.json`（进图→移动(含被挡一步)→怪物生成→击杀→掉落落地→切图→小退→再进）与 `golden/session.txt` **逐行一致**；含红检（改掉必掉率 ⇒ 地面物品数必变）。`basic.txt` 同步扩展到统一格式后仍逐行一致 |
| tick P99 不劣化 | 500/1000/2000 实体 = **639µs / 1903µs / 4855µs**（基线 662/1633/3882）。500 档优于基线、1000 档 +16%、2000 档落在本机噪声带（同批多次实测 3.88–8.82ms，并行线在跑）⇒ **2000 档的"不劣化"未敢断言，留 M5 专用压测复测**；已消除一处每 tick 分配（`by_map` 改复用缓冲） |

## 新增实现

- `crates/world/src/session.rs`：世界侧阶段机（`NotInWorld/InWorld/Left`）+ 进图/切图/掉线/小退/再进 + 显式错误枚举；
  切图会整体清空视野列表；小退再进得到**新 ActorId**
- `crates/world/src/combat.rs`：战斗子集逐字移植（`GetAttackPower`/`GetBaseAttackPoewr`/`_Attack`/
  `GetHitStruckDamage`/`StruckDamage`/`DamageHealth`）+ `GetGoldShape` + `CalcGetExp`/`WinExp`/`GetExp`（单步升级）
  + `MonsterRow` + `drop_position`（`GetDropPosition` 扫描序子集）
- `world.rs`：多地图（`maps: Vec<MapGrid>`）、同种子 RNG、`Command::{SpawnMonster,Kill,Attack}`、
  死亡结算（掉落落地 + 经验给击杀者）、`floor_items_sorted()` 输出面、AOI 分组复用缓冲
- 依赖：`crates/world` 增加两个**内部 path 依赖**（`mir2-data`/`mir2-formula`，均为已对拍的模型与公式）；
  `no_parallel.rs` 白名单同步收紧为"只许这三个内部 path 依赖 + 禁用清单不变"（含"内部依赖必须是 path 依赖"的断言）

## 对齐过程中修掉/登记的问题

1. **切图后"再进"必须用会话当前地图**：Rust 测试驱动最初用会话初始地图 ⇒ 首个差异 `ent 3 0 …` vs `ent 3 1 …`；
   统一为"会话当前地图（切图时更新）"后逐行一致
2. **`hp` 默认值不能是 0**：0 在语义上等于"已死"，会让死亡结算把刚进图的玩家当死者（实测踩到并修）
3. **P99 回归**：每 tick `vec![Vec::new(); maps]` 分配 ⇒ 用复用缓冲消除（500/1000 档回到基线内）
