== 等价性要点 ==
1. 严格大于：`GroupMembers.Count > GroupMembersMax`（Operate.cs:855）⇒ 组内实际可到 Max+1。
2. 出队序：立即帧（源码调用序）先发；RM_* 帧入队后在同一 Run 按 (byte)wIdent 升序出队。
   LeaveGroup 的 RM_GROUPMESSAGE(253) 与 RM_GROUPCANCEL(156) 同落退出者 ⇒ 线上序为
   SM_GROUPCANCEL(666) 先、SM_SYSMESSAGE(100) 后（最易错的一处，已用整条事件向量钉死）。
3. JoinGroup 两次（团长 + 新成员）各发一条「已加入小组」组队说词（CreateGroup 场景）。
4. CancelGroup 的「你的小组被解散了.」用**团长自己**的 GroupOwner 找成员表；团长自己也已退组时
   GroupOwner==0 ⇒ 无该文案（DelMember(团长自己) 路径）。
5. SysMsg(Red) 走 RM_SYSMESSAGE（优先级 252，排队）⇒ 与「立即帧之后」的出队序一致。
