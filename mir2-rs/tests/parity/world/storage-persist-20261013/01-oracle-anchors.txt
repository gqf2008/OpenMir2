**关键前提（决定 Rust 侧不从旧记录取长度/内容）**：`MakeSaveRcd` 的载体是**新建**记录 ——

$ grep -n 'CharacterDataInfo humanRcd = new CharacterDataInfo();\|CharacterData playerInfo = humanRcd.Data;' src/GameSrv/Word/WorldServer.cs

$ grep -n 'StorageItems = new ServerUserItem\[50\];' src/OpenMir2/Packets/ServerPackets/PlayerDataInfo.cs
```

```

⇒ `humanRcd.Data.StorageItems` 恒是构造期新分配的 50 槽（全 null），**不是**读档记录的数组。
⇒ 每次存档都从**空槽**开始：`StorageItemList[i]` 写槽 i、余下槽填 `DelfautItem`（非 null）。
⇒ Rust `storage_items_for_save` 恒产出 `STORAGE_SAVE_SLOTS = 50` 槽（尾槽 `default_server_item()`），
**不**受记录原长影响（否则「取回后旧物品留在尾槽」会是隐性分叉）。
