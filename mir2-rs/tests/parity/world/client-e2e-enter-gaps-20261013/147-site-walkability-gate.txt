一句话
====================================================================================================
`check_mongen_dense_points.py` 此前只能判「图在不在 `MapInfo`」（`enterable=yes/no`），**不判**
「站不站得住 / 冻结客户端有没有这张图」。本片补上这两条：给 `--map-dir`/`--client-map-dir` 时
按部署 `.map` 的 **12B 格**判 `tile=Walk|LowWall|HighWall|missing`、并判 `clientmap=yes/no`；
`--best-point` 只选可站立候选；`--require-walkable`/`--require-client-map` fail-closed。
真机部署实测牙齿：**`MapInfo` 说 `enterable=yes` 但实际不能用的候选真有**——
`D10071 (20,20) E=59.533`（并列第一密）`tile=LowWall`；`M100A/B/C` `tile=missing clientmap=no`
（两边都没有 `.map`）；`M100 (150,150)` `tile=HighWall`。旧工具会把这些当合法候选推给窗口。

A. 归因与口径（oracle / 部署锚点）
====================================================================================================
* `.map` 格式**不在本片新建**：定案在 `mir2-rs/crates/envir/src/mapfile.rs`（卡
  `openmir2-m2-map-loading`，comment `862396f8` 在部署件上定案）。本片**内联同口径**只读 12B，
  **不 import 生产 crate**（判据脚本必须 `python -I -B` 零依赖可跑）：
  - 头 52B；偏移 `0..3` = `int16 Width/Height`（小端）；`k = x * Height + y`；
  - 格 12B = `wBkImg u16` + `wMidImg u16` + `wFrImg u16` + 6×`u8`；
  - `wBkImg` bit15 = HighWall、`wFrImg` bit15 = LowWall、**Low 覆盖 High**、`wMidImg` 不参与。
  - 只 `seek+read(12)`，不加载整图（700×700 图 = 5.88MB；跨图排行 547 候选必须 O(1) 内存）。
* 「图存在」口径沿用片㉑：oracle `MapMgr.FindMap` 按**逻辑名**（`|` 前）查表；落盘文件名是
  `|` 后（`[DB|DM011]` ⇒ `DM011.map`）⇒ 本片三种都试（整字段/`|` 前/`|` 后，大小写不敏感）。
* 「冻结客户端有没有这张图」= 客户端 `Map/*.map` 存在性（**客户端改不了**，缺图就渲染不出怪）。
* 为什么这是烧窗前置：`③b` 要 root 把 `aaa` 站到候选点再看同屏出现帧；候选若落在墙上或
  客户端无图，窗口必然白烧（且离线可预防）。root 00:4x ① 明确「换怪密点（例如比奇省郊外，
  **或 MonGen 里密度高的图**）」⇒ 跨图候选正是最需要这条门的地方。

B. 本片改动（写集 = 本卡证据目录，1 文件：`check_mongen_dense_points.py`）
====================================================================================================
新增（缺目录 ⇒ 旧输出逐字节不变）：
  1. `map_name_candidates` / `resolve_map_file`：逻辑名 ⇒ `.map` 字节（大小写不敏感）。
  2. `tile_attr_from_bytes` / `read_tile` / `is_walkable`：O(1) 内存判单格；
     缺目录/缺图/坏头 ⇒ `missing`/`bad`（**绝不当 `Walk`**）。
  3. `client_has_map`：冻结客户端是否带图（未给目录 ⇒ `None`，不判不记）。
  4. `tile_suffix` / `client_suffix`：追加 ` tile=…` / ` clientmap=…`；目录为空 ⇒ 空串。
  5. `site_ok` / `require_site_check`：候选过滤与 fail-closed 机判（缺目录 ⇒ `PREREQ_RED`）。
  6. CLI：`--map-dir` / `--client-map-dir` / `--require-walkable` / `--require-client-map`。
     `--rank`/`--best-point`/`--point(s)`/`--start-point` 四条路径全部接入；
     **`--best-point` 只选 `tile=Walk`（且客户端带图）的候选**，并打印跳过的候选数；
     全被过滤 ⇒ `RED` rc=1（不静默回退到墙上）。
  7. `--selftest` **30 → 60**（新增 30 条：12B 格解析/Low 覆盖 High/OOR/BAD、文件解析
     大小写与 `|` 前后、缺图/坏头、后缀缺目录为空、`site_ok` 四态、`require_site_check` 6 态、
     旧输出不含 `tile=`/`clientmap=`）。
