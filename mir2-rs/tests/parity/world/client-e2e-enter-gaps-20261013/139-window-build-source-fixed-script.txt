A. 缺陷（机判，不是散文）—— 用默认构建源，③ 窗口会烧在「旧版式读数」上
----------------------------------------------------------------------------------------------------
[A1] root 的一键窗口脚本 `E:/tmp/openmir2-watch/client-e2e-window.sh:6-7`（逐字）：
```
w=/e/tmp/openmir2-watch; repo=/e/Users/gxh/Documents/GitHub/OpenMir2
tgt='E:\tmp\openmir2-merge-target'; logdir='E:\tmp\client-e2e\stack'
```
     其中 `repo` = **共享主检出**（现为 rev 车道 worktree）。第 2 步是
     `( cd "$repo/mir2-rs" && CARGO_TARGET_DIR="$tgt" cargo build … )`，第 3 步用 `-RustBinDir "$tgt\debug"` 起栈。

[A2] 机判（本片当场重跑；命令与原始输出见 `141-gates.txt`）：
