A. 交付物
----------
新工具 `aoi_visibility_pair.py`（本目录）：消费两侧 `capture.jsonl`（`export_s2c.ps1` 解码的
**客户端实际收到** s2c 帧），抽出 `SM_TURN(10)+SM_FEATURECHANGED(41)` 相邻出现对 = 该侧同屏出现的
actor 集合；判据：
  --expect none    两侧出现对都为 0 ⇒ GREEN（该点确实无怪）
  --expect visible 两侧都 >= --min-pairs（默认 1）⇒ GREEN（同屏有怪）
  --expect report   只报告
  --strict-recogs   额外要求两侧 recog 集合相等（70 §E step3 的假设；默认关，窗口验证后再开）
退出码 0/1/2（2=PREREQ 缺件/不可解析，绝不静默通过）。
抽取逻辑**直接 import 复用** `check_client_s2c_frames.py` 的 load_capture/s2c/appearance_pairs，
杜绝口径漂移；`--selftest` 11 条（含 none/visible/计数/缺件/严格 recog/相邻配对）不依赖外部件。

  python -I -B aoi_visibility_pair.py --left <rust>/capture.jsonl --right <csharp>/capture.jsonl \
         --expect visible --min-pairs 1            # 密集点 (287,620)/(256,572)

         --expect none                             # 无怪点 (291,666)
