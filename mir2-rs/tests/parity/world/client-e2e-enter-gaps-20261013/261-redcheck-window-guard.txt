#    且以 `|| exit 1` 短路（否则门 RED 仍会暂停车队/构建/起栈）。


# 3) 为什么变体 B 不真跑

`start` 的真跑会 `lanes-pause.sh`（暂停整个车队）+ `cargo build` + 起栈（占 9 个游戏端口）——
这正是 `brief` 明令「车道不要自己起栈占端口」的面，也是本片要防的副作用。故对 `start` 只做
**静态咬合**（门行号 < `lanes-pause` 行号 + `|| exit 1` 存在），门本身的**行为**由变体 A 的
三态注入（RED rc=1 / GREEN rc=0 / 用法 rc=2）+ §260 的真跑覆盖。

# 4) 判级

**L**（脚本/门 + 只读证据，零生产代码）。牙齿 = 变体 A（行为，双向）+ 变体 B（静态）。
