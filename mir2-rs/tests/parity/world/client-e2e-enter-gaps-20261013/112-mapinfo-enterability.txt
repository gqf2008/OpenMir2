一句话
====================================================================================================
片⑳ 的 `check_mongen_dense_points.py --all-maps` 给出的跨图 Top-20（`D10071` E=59.533 等）
此前只能标「**可进入性未证**」；本片把它变成**机判**：按 oracle `MapMgr.FindMap` 的口径
（逻辑名 = `|` 前）在 `Envir/MapInfo.txt` 查表，命中即 `enterable=yes`，并可 `--require-enterable`
fail-closed（候选图不在 MapInfo ⇒ RED）。**真机部署实测：MonGen 的 207 张图全部 `enterable=yes`**
⇒ 跨图候选在「图存在」这一层**不存在**烧窗风险；换图复测（root ①）可以放心选密度高的图。
本片**不改**任何既有输出：不给 `--mapinfo` 时，旧命令逐字节不变（见 §E 回归）。

A. 归因与口径（oracle 锚点）
====================================================================================================
* oracle `WorldServer.Merchant.cs:8-25` 的 `MerchantInitialize` 门 = `SystemShare.MapMgr.FindMap(MapName) != null`；
  owner 2026-10-13 10:50 裁决已钉死：`FindMap` 按**逻辑名**（`|` 前）查表
  （`Envir/MapInfo.txt` 的 `[DB|DM011]`/`[ZM6|D5071]`/`[jiaren|0150]` 都在 ⇒ `131→131` 门不触发）。
* 本片把同一口径用到 **MonGen 的图字段**上：MonGen 行首字段（本部署无 `|`）取 `|` 前，
  与 MapInfo 的 `[...]` 首字段 `|` 前集合比对。
  ⇒ 命中 = oracle 侧该图会被加载（可进入）；未命中 = 该图在 MonGen 里但 MapInfo 不含它
  ⇒ 进图/刷怪在 oracle 侧就不成立，选它做 ③b 就是「必然无怪」的烧窗。

B. 本片改动（写集 = 本卡证据目录，1 文件）
====================================================================================================
`check_mongen_dense_points.py`（唯一改动文件）：
  1. 新增 `parse_mapinfo(text)`：解析 `Envir/MapInfo.txt` 的 `[...]` 行，取首字段 `|` 前（逻辑名）。
  2. 新增 `is_enterable(map_name, keys)` / `enterable_suffix(map_name, keys)`：`|` 前口径；
     `keys is None`（未给 `--mapinfo`）时返回空串 ⇒ **旧输出逐字节不变**。
  3. 新增 `require_enterable_check(names, keys, require)`：被报告/被选中的候选图有任一未命中 ⇒
     `RED(1)`；`--require-enterable` 未给 `--mapinfo` ⇒ `PREREQ_RED(2)`；全命中 ⇒ `OK`。
  4. CLI 新增 `--mapinfo <Envir/MapInfo.txt>` 与 `--require-enterable`；`--all-maps`/`--rank`/
     `--best-point`/点判定四条路径都接入（只在给了 `--mapinfo` 时追加 `enterable=`）。
  5. `--selftest` **22 → 30**（新增 8 条：mapinfo 解析、`|` 前口径、缺 `--mapinfo` 不变、
     require 绿/红/PREREQ/不 require 恒绿、旧输出无 `enterable=`）。

F. 边界 / 残留（不静默）
====================================================================================================
* 本片只判「图在 MapInfo 里」（= oracle `FindMap != null` 这一层）。**不判**：该图 `MapInfo` 行上的
  `NORECONNECT`/`NORANDOMMOVE`/`SAFE` 等属性对「坐标落点是否可站」的影响、`x,y` 是否落在
  阻挡格、Rust 侧该图是否已加载。⇒ 换图窗口仍须实拍（runbook §1 站位 + §4 判据）。
* 不给 `--mapinfo` 时的既有行为（含 `--all-maps` 菜单）**零变化**；`--require-enterable` 是可选门。
* `tests/parity/m3/**`（m3bag/driver 写集）与 root 的 `client-e2e-window.sh` **未触碰**。
