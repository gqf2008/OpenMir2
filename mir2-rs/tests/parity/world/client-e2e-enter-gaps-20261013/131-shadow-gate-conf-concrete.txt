A. 本片修的是什么（一个逻辑变更：让「影子 gate」从「说一句」变成「照着敲就能跑」）
----------------------------------------------------------------------------------------------------
片㉔ 把「起代理前的抓包拓扑」补进计划、片㉕ 补了「收」，但**影子 gate 本身怎么起**只留了散文 +
未替换占位：计划里 `--shadow-config <影子 RunGate/config.conf>`、Rust 段的
`-ArgumentList '<影子 conf>' -WorkingDirectory '<conf 目录>'` ⇒ root 必须现场猜路径、猜 conf 内容。
两处都会**白烧一次性窗口**，第二处还会**假绿**（见 B）。

[A1] **C# 影子不能只改 conf、仍起原 exe。** oracle 的 conf 路径写死为 exe 目录：
     `src/GameGate/Conf/ConfigManager.cs:5`
       `private static readonly string fileName = Path.Combine(AppContext.BaseDirectory, "config.conf");`
     且 `src/GameGate/Program.cs:14` 的 `Main(string[] args)` **不解析 conf 参数**（`args` 只喂
     `HostApplicationBuilder(args)`，`:42`）；`appsettings.json` 同样是 `SetBasePath(AppContext.BaseDirectory)`（`:31`）。
     ⇒ 直接 `Start-Process E:\MirServer\RunGate\GameGate.exe` 时 `BaseDirectory` = 原目录 ⇒ **读回原
     config（`GatePort1=7200`）**，不是那份改好的影子 conf。后果二连：
       ① 影子仍绑 7200 ⇒ `mir2_proxy.py --map 7200=127.0.0.1:7600` 绑不上 ⇒ 无 capture（白烧）；
       ② 前置门 `check_csharp_capture_preflight.py --shadow-config <改好的 conf>` 读的是**文件**、
          不是进程实际读的 config ⇒ 影子分支 **GREEN**，而线上进程其实在 7200 ⇒ **false-green**。
     正解：影子 = **自己的目录 + 自己目录下的 config.conf**（整目录拷贝）。

[A2] **conf 必须 cp936 原样改。** 部署件 `E:/MirServer/RunGate/config.conf` 4456 B，含 **1523 个非 ASCII
     字节**（`[MagicInterval]` / `[Strings]` 的中文技能名），CRLF 236 处。用 UTF-8 解码再写回会把 GBK
     字节改坏；直接照抄 `Count=3` 又会让 Rust 影子多绑 7201/7202 ⇒ 代理仍抢不到 7200。
     ⇒ 用 `[Text.Encoding]::GetEncoding(936)` 读、只把两个**数字**替换掉（零宽断言，不动行尾 CRLF）、
        再按 cp936 写回；Rust 侧镜像同一份 conf（`bins/game-gate/src/config.rs:13-19` 就是这套 INI，
        `main.rs:81-84` 取 argv[1] 当 conf 路径）。
