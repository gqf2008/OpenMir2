# 0) 一句话

`213-highhp-family-audit.txt` §4 登记的 `SM_STRUCK(31)` 同源 GAP 现已实现**客户端布局**：
生产默认发「头 `LoWord(HP)/HiWord(HP)/伤害` + 尾 `MessageBodyWL.Param1=MaxHP`」，
`MIR2_CLIENT_ABILITY_LAYOUT=0` 才回 oracle 逐字节（`param=HP, tag=MaxHP, 尾.Param1=feature`）。
与 52/53 同源同开关；判据 = 客户端源码逐字节锚 + 构造级逐字节断言 + 改坏必红（222）。

# 1) 客户端要求的布局（冻结客户端源码，`MirClient@c61d912d`）

`Source/Common/Grobal2.pas:39  HIGHHP = True;`

`Source/MirClient/ClMain.pas:10238` 的 `SM_STRUCK` 支：

```pascal
    SM_STRUCK:
      begin
        DecodeBuffer(body, @wl, SizeOf(TMessageBodyWL));      // 尾 = 16B {Param1,Param2,Tag1,Tag2}
        ...
        Actor.UpdateMsg(SM_STRUCK, wl.lTag2, 0, msg.series { damage },
          wl.lParam1, wl.lParam2, '', wl.lTag1);
{$IF HIGHHP}
          Actor.m_Abil.HP    := DWORD(Makelong(msg.param, msg.tag));   // 头两格拼 32 位 HP
          Actor.m_Abil.MaxHP := DWORD(wl.lParam1);                     // MaxHP 在**尾** Param1
{$ELSE}
          Actor.m_Abil.HP    := msg.param;
          Actor.m_Abil.MaxHP := msg.tag;
{$IFEND}
```

⇒ 冻结客户端（`HIGHHP=True`）要的 `SM_STRUCK` =
**头 `(Recog=受击者, param=LoWord(HP), tag=HiWord(HP), series=伤害)`**
+ **尾 `Encode(MessageBodyWL{ Param1=MaxHP, Param2=CharStatus, Tag1=命中者, Tag2=mag })`**。

`feature` 在 `HIGHHP` 下**不被客户端消费**：`ClMain.pas:10266` 把 `wl.lParam1` 当 `nFeature` 传进
`TActor.UpdateMsg`，而 `TActor.SendMsg` 的 `SM_STRUCK` 支（`Actor.pas:1833-1839`）只取 `nSound`
（→ `m_nHiterCode`），`nFeature` 随即被 `Actor.m_Abil.MaxHP := wl.lParam1` 顶掉 ⇒ 客户端布局不再携带 feature。

# 2) oracle 发的是什么（C# 参照实现）

`src/M2Server/Player/PlayObject.Message.cs:1601`：

```csharp
ClientMsg = Messages.MakeMessage(Messages.SM_STRUCK, processMsg.ActorId,
                                 baseObject.WAbil.HP, baseObject.WAbil.MaxHP, processMsg.wParam);
MessageBodyWL struckMessage = default;
struckMessage.Param1 = baseObject.GetFeature(this);   // ← oracle 的 Param1 = feature
struckMessage.Param2 = baseObject.CharStatus;
struckMessage.Tag1   = processMsg.nParam3;            // 命中者
struckMessage.Tag2   = (wIdent == RM_STRUCK_MAG) ? 1 : 0;
SendSocket(ClientMsg, EDCode.EncodePacket(struckMessage));
```

⇒ oracle = 头 `(HP, MaxHP, 伤害)` + 尾 `{Param1=feature, ...}`（非 HIGHHP 口径）。
两者**不可同时满足** ⇒ 与 52 的 58B / 53 的 `TCharDesc` 尾同款 §6.0-3 故意偏离：**默认以冻结客户端为准**。
