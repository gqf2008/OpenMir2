====================================================================================================

    处理分支在 `Source/MirClient/ClMain.pas:9621` 的 `case msg.ident of` ⇒ `:9622 ClientGetServerConfig`。
  * oracle：`src/OpenMir2/Messages.cs:433 SM_SERVERCONFIG = 11029`；发送点
    `src/M2Server/Player/PlayObject.Base.cs:961-963 SendServerConfig()` → `SendDefMessage(Messages.SM_SERVERCONFIG, …)`。

    （SM_TURN=10 / SM_FEATURECHANGED=41 / SM_ABILITY=52 / SM_SUBABILITY=752 两侧相同）。
  ⇒ 服务端发的 11029 落在客户端 `case msg.ident of` 的**未知分支**（直接忽略），

    也永不执行。

B. 因此 `g_boCanStartRun` 是**缺省值 True**，不是「读未初始化栈恒假」
====================================================================================================
  * `Source/MirClient/MShare.pas:1998 g_boCanStartRun: Boolean = True;`（同类：`:1994-1996`
    `g_boCanRunHuman/Mon/Npc = True`）。
  * 跑门 `Source/MirClient/ClMain.pas:2193 if g_boCanStartRun or (g_nRunReadyCount >= 1)` ⇒ 恒真。
  * 片⑥ 的推论「`boCanStartRun` 读 TClientConf offset>17 的未初始化栈 ⇒ 实测恒假」依赖
    `ClientGetServerConfig` **被执行**；执行它的前提是帧号 = 20002。两者不能同时成立。
  ⇒ 「跑不动」不是（至少不只是）该帧的体布局造成的。（片⑥ 的 58B TAbility/HUD 读数仍成立，那是 52 帧。）

C. caRun 分支的真正下游门（若要继续查「跑」，应查这几处）
====================================================================================================
  `ClMain.pas:2115 case g_ChrAction of` → `:2190 caRun:`：
    1) `:2196 crun := g_MySelf.CanRun`；`Actor.pas:2162-2167`：`m_Abil.HP < RUN_MINHEALTH(=10, :22) ⇒ -1`
       （58B 布局下 HUD 19/19 ⇒ 此处应为 1）；
    2) `:2223 GetDistance(mx,my,dx,dy) >= 2`（点得太近 ⇒ 落 `else` → `CM_TURN`）；
    3) `:2225 IsUnLockAction()`（`ClMain.pas:7760`：`ActionFailLock or g_boMapMoving or g_boServerChanging ⇒ False`）；
    4) `:2227 g_PlayScene.CanRun(currX,currY,mx,my)`（`PlayScn.pas:3101-3119`）：要求
       **下一格 + 目标格**都 `CanWalkEx`（`Map.CanMove` 且 `not CrashManEx`）——怪物占格会返回 False ⇒ 落
       `:2241 g_ChrAction := caWalk`（**只走不跑**）。
    5) `g_ChrAction` 何时变 caRun：地图上左键点 >1 格 ⇒ `ClMain.pas:5446-5463 g_ChrAction := caRun`
       （点 ≤1 格只发 `CM_TURN`）。⇒ 若驱动点击距离 ≤1 格、或 run 两格路径被怪占，则不产生 `CM_RUN`。
  ⇒ 下一步应在这四处取真机实测（例如：把角色放在空旷格并点 ≥3 格远；或临时关掉怪物占格），
    而不是改 11029 的体布局。
