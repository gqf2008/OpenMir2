# 3) R7「预构建二进制 ↔ 构建源出处」（收 `175` §F 已登记的 R6 界限）

`check_rust_window_preflight.py` 新增：

* **录制模式** `--record-provenance <path>`（`cargo build` 之后跑）：
  ```
  $ python -I -B check_rust_window_preflight.py --repo E:/tmp/m2svr-window-origin --ref HEAD \
      --target-dir E:/tmp/m2svr-window-target \
      --record-provenance E:/tmp/m2svr-window-target/window-provenance.json
  R7_PROVENANCE_RECORDED source_head=ae64439246cba0ea5e7cc406112284b83d1c69cc bins=6 \
      -> E:/tmp/m2svr-window-target/window-provenance.json
  rc=0
  ```
  清单 = `{version, source_head, target_dir, bins:{<exe>:{sha256,bytes}}}`（六件 = 窗口 `cargo build`
  的 `-p` 列表，逐字同源；缺任一件 ⇒ 录不出、拒写半份）。
* **判据模式** `--target-dir <dir> --provenance <path>`（R7）：
  * 清单 `source_head` == 当前 `--ref` ⇒ 继续；否则比 `git diff --name-only <head> <ref> -- <RUST_BUILD_PATHS>`：
    **零差异**（只动 `docs/` 之类）⇒ OK（cargo 不重链，exe 仍逐字节有效，**不假红**）；
    **有差异** ⇒ RED（exe 来自另一棵树）；
  * 每件 exe 的 sha256 必须与清单**逐字节相等**；缺件/清单无记录 ⇒ RED；
  * 清单缺失 ⇒ **PREREQ_RED**（fail-closed；不传 `--target-dir/--provenance` 时打 INFO 跳过，向后兼容）。
* `RUST_BUILD_PATHS = mir2-rs/bins | mir2-rs/crates | mir2-rs/Cargo.toml | mir2-rs/Cargo.lock`
  （R7 只用这组，**不用** R6 的 `PRODUCTION_PATHS`：后者含会变的 `src/BotSrv`，那不影响这六个 exe）。
* `window_handoff.py`：G1 透传 `--target-dir/--provenance`；G1 文案 `R1..R6` → `R1..R7`；
  `--plan` §0a 新增 `0a-2)` 录清单步骤（照抄可执行，无占位）。
