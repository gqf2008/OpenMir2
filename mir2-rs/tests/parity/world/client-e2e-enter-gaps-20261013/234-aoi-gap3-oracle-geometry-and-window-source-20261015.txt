# 1) ③ 的 oracle 侧同点位对照（本片新增；机判可复跑）

## 1a) oracle 锚点（出生几何）

```
src/GameSrv/Word/WorldServer.MonGen.cs:825-826
    nX = monGen.X - monGen.Range + Random(monGen.Range * 2 + 1);
    nY = monGen.Y - monGen.Range + Random(monGen.Range * 2 + 1);
```
⇒ 出生点均匀落在 **正方形** `[X-R, X+R] × [Y-R, Y+R]`（Chebyshev 口径），不是圆/菱形。
「点在框外且到最近框 Chebyshev = d」⇒ **新出生**的怪至少离该点 d 格；`view_range < d` 时该点窗口内
**不可能有「出生即看见」的怪**（游走怪另算，机判工具已在输出里显式登记这一口径）。
