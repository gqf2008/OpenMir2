openmir2-client-e2e-enter-gaps 缺口②「同屏无怪」· oracle 锚点与 Rust 现状（2026-10-13，m2-svr / openmir2-worker-11）
====================================================================================================

一句话：oracle 玩家实体（`PlayObject`）构造器把 `ViewRange` 置 **12**，而 Rust 生产宿主
`new_player_entity` 从未置它 ⇒ 玩家 AOI 扫描窗口只有 **11×11**（缺省 5），不是 oracle 的 **25×25**；
Chebyshev 距离 **6..12** 的怪/其他 actor 不进 `visible_actors`，`drain_aoi_downlink` 也就不会发
出现帧（`SM_TURN(10)`+`SM_FEATURECHANGED(41)`）⇒ 客户端在出生点/城墙外**同屏少怪**。

本片只动 `bins/game-svr/src/main.rs`（单行 + 两条用例）；不动任何模拟/取数/RNG 语义。

C. 影响面 / 归因（为什么这属于卡上「同屏无怪」）
--------------------------------------------------------------------------------
- `drain_aoi_downlink`（mir2-rs/bins/game-svr/src/main.rs:3308）只对 `visible_actors` 里
  `flag == Show` 的对象发 `SM_TURN(10)` + `SM_FEATURECHANGED(41)`；不在窗口内的对象**从不出现**。
- 因此窗口 11×11 vs 25×25 直接改变客户端**能看到哪些怪**（差值环带 = 距离 6..12）。
- 这与「世界 tick 无实体」是两回事：同一份真机日志里 `实体内 9525`、`same_map=1726`（见 `10-…`）；
  这里是**窗口太小** ⇒ 客户端同屏少怪，正是 owner 实测「出生点周围无怪」的可判原因之一。
