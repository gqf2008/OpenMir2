口径：都在**钉住的 head** 上跑；改件用 `E:/tmp/m2svr-burst17/mut/*.py` 外部副本，**不动工作树**；
每条都贴「命令 + 原始输出 + rc」。红线：改动落在**生产路径**（出现帧体解码）或**窗口门禁注册**上，

---- MUT-1：edcode 解码密钥写错（`SEED = 0xAC` → `0xAD`）⇒ actor 名解错 ⇒ 直方图门 RED ----
```
$ sed 's/^SEED = 0xAC$/SEED = 0xAD/' check_appearance_pairs.py > <tmp>/mut1.py
$ python -I -B <tmp>/mut1.py --capture capture-client-viewrange12-seed42.jsonl \
    --min-pairs 13 --expect-names "稻草人=10,鹿=3"

  actor=0x00000332 (300,616) feature=0x011a0113 raceImg=19 name=纯耻墒.344/
  RED: ShowName 直方图不同：got={'纯耻墒.344': 10, '酶.344': 3} expect={'稻草人': 10, '鹿': 3}
RESULT: RED
rc=1                        # 期望 RED(1) —— GREEN 读数确由正确解码产生
```
---- MUT-2：`SM_TURN` 名尾不再解码（`decode(rest[first:])` → `b""`）⇒ 体长不符 ⇒ RED ----
```

      check_appearance_pairs.py > <tmp>/mut2.py
$ python -I -B <tmp>/mut2.py --capture capture-client-viewrange12-seed42.jsonl \
    --min-pairs 13 --expect-names "稻草人=10,鹿=3"

  RED: actor 0x00000322 体长解码 8 != 帧声明 18
  RED: actor 0x00000309 体长解码 8 != 帧声明 18
  …（13 条 actor 体长不符）…
RESULT: RED
rc=1                        # 期望 RED(1) —— 名尾=0 与帧声明 body_len 矛盾，必被咬住
```
