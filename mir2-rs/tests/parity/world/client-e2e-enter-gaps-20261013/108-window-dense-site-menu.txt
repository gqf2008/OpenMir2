A. 口径（与片⑯ 同一函数，不改语义）
====================================================================================================
* 生成框 = oracle `WorldServer.MonGen.cs:825-826` 的正方形 `[X-R,X+R] x [Y-R,Y+R]`（Chebyshev）。
* 期望出生怪数 `E = Σ_box  Count * |窗口 ∩ 框| / |框|`（`--view-range 12` ⇒ 窗口 = 25x25）。
  **只算出生**（不含游走）：`E==0` ⇒ 窗口内不会有**新出生**的怪，不排除游走怪。
* 候选点 = 每个生成框**中心**（去重）；排行确定性 = `(-E, 图名, x, y)`。
* 数据源（只读）：`E:/MirServer/M2GameSvr/Envir/MonGen.txt`
  `sha256 = e5c39fb7eda66b70f82a61a5c2cea25df9cf0b6892b916fb6d579f88ff43748f`

### C.1 为什么**不**默认把这些当 ③b
1. **可进入性未证**：`aaa` 现在在 map 0。换成 `D10071` 等图需要同时改 `characters.map`，
   且该图必须在部署 `MapInfo`/Envir 里加载成功；副本/地牢可能有进入条件（或本部署未加载该图）。
   **窗口一次只有一趟**，不能拿「地图进不去」换掉一个已证可行的 map 0 点。
2. **`E` 只算出生**：小框（`range=0 count=1`）重叠处 `E` 是「多框叠加」的期望和，
   与实机「哪些怪真被留下/游走」仍有差；map 0 的 12.68 已经远超 ③b 的 `--min-pairs 1` 判据。
3. 若 owner/root 想在窗口里**顺手试**更密的图：优先 `D024 (50,50)`（`E=42.349`，一张图内多点可选、
   非单点孤例）或 `D2002 (21,23)`（`E=49.992`）；**必须**在窗口证据里如实写「换了图 + 图能否进」。
