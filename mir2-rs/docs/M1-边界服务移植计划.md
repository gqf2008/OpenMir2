## 2. 配置（沿用现网文件与键名，缺失必须报错退出 —— M1 验收④）

| 服务 | 文件 | 关键键 |
|---|---|---|
| LoginGate | `config.conf` | `[LoginGate] ServerAddr0/ServerPort0`(=5500)、`GateAddr0/GatePort0`(=7000)、`Count`；`[Integer] ClientTimeOutTime/NomClientPacketSize/MaxClientPacketCount`；`[Switch] CheckNewIDOfIP/CheckNullSession/DefenceCCPacket/KickOverPacketSize` |
| SelGate | `config.conf`（另有遗留 `Config.ini`） | `[SelGate] ServerAddr0/ServerPort0`(=5100)、`GatePort0`(=7100)、`LsvServer/LsvServerPort`(=16005) |
| LoginSrv | `LogSrv.ini` | `[Server] GateAddr/GatePort`(=5500 监听)、`ServerAddr/ServerPort`(=5600)、`ReadyServers/EnableMakingID/EnableGetbackPassword/UnLockAccount*`、`DBServer/DBSPort` |
| DBSrv | `dbsvr.conf` | `[DataBase] DbType/ConnctionString/Storeage`(默认 MySQL)、`[Setup] ServerAddr/ServerPort`(=6000)、`GateAddr/GatePort`(=5100)、`ServerName/DBName/HeroDB/DenyChrName/DELMaxLevel`、`[Server] IDSAddr/IDSPort`(=5600)、`MarketAddr/MarketPort`(=5700) |

- `ConnctionString` 是 **MySQL Connector 风格**（`server=..;uid=..;pwd=..;database=..;`），
  Rust 侧需解析后转 `sqlx` 的 URL 形式（键名照旧读，不改配置）。
- `Storeage`（原拼写照抄）是**存储插件名**；缺插件/连不上库必须启动即报错并给非零退出码。
- 部署目录另有多份遗留文件（`AddrTable.txt`/`ServerAddr.txt`/`ServerInfo.txt`/`PlugList.txt` 等，
  内容含历史 IP）；`TODO(核实)`：各服务实际读了哪些、空文件时行为如何。

## 4. 已完成的字节级基础（本批）

- **内部帧编解码** `crates/protocol::internal`：
  `[0x04][type:u8][socket_id: i32 UTF-16 码元数 + UTF-16LE][data_len:i16][data: i32 + bytes]`，
  线上 = 6B `ServerDataPacket`(`PacketCode`=0xAA9AAA9A, `PacketLen`=体长) + 体。
  实测自 C# 真身（`tests/parity/oracle` 生成 15 条 `kind:"internal"` 向量：含中文、emoji（代理对）、
  `DataLen≠data.len()` 的独立字段、空会话号/空载荷）。
- 门禁：`cargo test -p mir2-protocol`（字面量金标准单测）+ oracle 集成测试逐条对拍；
  破坏者自检：把对象头 `0x04` 改成 `0x05` ⇒ 单测与集成门禁同时红（留证于提交说明）。

## 6. 风险与对策

1. **MemoryPack 其余结构**（`CharacterDataInfo` 等大结构含集合与嵌套）——同一 oracle 套路逐类测；
   风险最高的是集合/字典的编码序。
2. **遗留配置的读取优先级**（多份同名/历史文件）——以「现网进程实际行为」为准，用日志/探针核实，不臆测。
3. **oracle 版本漂移**（§13.4 已登记）——混跑时以**运行中的** C# 进程为对端，不假设其与源码一致；
   发现不符先记证再定策。
4. **端口占用**：混跑需临时错开端口（Rust 服务换端口 + 对端配置指向它），
   不得改动 `E:\MirServer` 的冻结部署（照 C 线影子拓扑的教训：先做「有桩/无桩对照」）。
