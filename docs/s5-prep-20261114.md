### 3.2 谁引用 / 切到 world-bevy 的等价面（逐项结论）

- **`World` 门面**（`game-svr` 680 次）：world-bevy 只有 `EcsStore<T>` + `TickRunner` +
  `TickStage`（S1 内核），**没有** `World`；`World` 仍在 `crates/world`。
- **`EntitySpawn`（142 字段）/ `entity` 模块**：world-bevy 只有 25 个 `Component`（P0 骨架）
  与 `CoreIdentity`；`EntitySpawn` 与 `EntityRef` / `EntityMut` 视图都在 world，**无等价物**。
- **24 个模拟模块**（`action`/`aoi`/`buff`/`castle`/`castle_tax`/`combat`/`ctor_fold`/`death_drop`/
  `guild`/`magic`/`magic_effect`/`map`/`merchant`/`monai`/`mongen`/`msgqueue`/`npc`/`party`/`run_gap`/
  `session`/`slave`/`space_move`/`special_monster`/`world`）：world-bevy **一个都没有**
  （只有 `components` / `ecs` / `tick` + D3 掉落系统）。
- **映射近似（但 API 不同名/不同形）**：`EcsStore<T>` ↔ `EntityStore`、`TickRunner`/`TickStage` ↔
  `World::tick` 的内部阶段链、`MapsRes`/`Atlas` ↔ 地图绑定、`drop_budget_system`/`plan_drops` ↔ 掉落预算。
- **同名异型（假等价陷阱）**：`MerchantState`、`NpcState` 两处名字在两侧都存在，但
  world-bevy 的是**泛型组件包装**（`MerchantState<M>` / `NpcState<N>`），world 的是**业务结构**
  （带 `new()`、被宿主直接构造）。按名字当等价物切会编译错。

### 4.1 阶段 1：只翻依赖指针（本 worktree，实验后已还原）

做法：把消费方 Cargo 清单的 `mir2-world` 用 **package 重命名别名**指到 world-bevy，
**不改任何 Rust 源码**（代码里仍写 `mir2_world::…`）：

```toml
mir2-world = { package = "mir2-world-bevy", path = "../../crates/world-bevy" }
```

| 实验 | 范围 | rc | 错误面 |
| --- | --- | --- | --- |
| E1 | 只切 `crates/envir` | 101 | 6 个：`map` 模块找不到（4），`MapGrid` / `CellAttribute` 未解析（2） |
| E2 | 只切 `tests/parity` | 101 | 16 行：`EntitySpawn` 未解析（6）、`World`/`Command` 命中 bevy prelude 私有绑定（4）、ctor fold 三型未解析（1）、`E0782 expected a type, found a trait`（1） |
| E3 | 只切 `game-svr` | 101 | 742 行 / 32 个文件：`World`（652）、`EntityRef`（10）、`merchant`/`castle`/`mongen` 模块（24）、`ACTOR_RACE_PLAY`/`PartyConfig`/`HideObserverKind` 等常量与类型（14）、`Command`（8）、宿主自己的 `msgqueue` 连带失配（4） |
| E4 | 三个消费方同时切 | 101 | 先停在 `mir2-envir`，其余随之级联（同 E1 + 消费链） |

**判读**：错误不是「改错名字」，而是 **API 整体缺位**。E2/E3 里 `World`/`Command` 报
「private」而不是「not found」的原因是：world-bevy 的 crate 根有 `use bevy_ecs::prelude::*`
的私有 glob 绑定，`bevy_ecs::World` / `Command` trait 占住了这两个名字，于是按别名解析时
命中私有项。**这也是 S5 必须做重名消歧的直接证据**。
