## 0. 口径来源（以夹具实测为准）

夹具两轮实测（见证据目录 README §2/§3）：

1. **`smframe.rs`**：新增 `sm_sysmessage(recog, f_color, b_color, msg)`（`sm_sysmessage` = 12B 头 +

   `KickUser`）；`run_ids_link` 经 `ev_tx` 把它交给 sim 线程（`GateEvent::KickAccount`）。
4. **`main.rs`**：
   - `OnlineRegistry` 由 `(chr,gate,socket)` 扩为 `OnlineEntry{account,chr_name,session_id,gate_idx,socket,actor_id}`；
     `online_find_for_kick` 按 `Account`（OrdinalIgnoreCase）**或** `SessionID` 匹配（`TCPNetChannel.cs:252`；
     语义细节见 §4.1 O-3）；
   - `handle_kick_account`（即时）：`FrontEngine.DeleteHuman` + 立即发 `SM_SYSMESSAGE` + 记入 `soft_close_pending`；
   - `drain_soft_close`（同一 tick 的**后段**；oracle 是下一 tick）：`CloseUser(旧)` + `World::disconnect`（= `BoSoftClose` 的 `MakeGhost`）；
   - **竞态复刻**：取档回复进图前先算 `in_save = engine.in_save_rcd_list(chr)`、
     `in_world = world.session(chr).stage == InWorld`；命中 ⇒ `handle_duplicate_enter(..., kick_old=in_world)`
     （旧不在 `PlayObjectList` ⇒ 只关新、不置踢旧标志）；未命中 ⇒ 正常进图（放行）。
   - `DbWiring.outstanding` 增带 `session_id/account`（用于进世界时登记在线表）。

### 3.2 逐字节锚点

- `sm_sysmessage_rebuilds_golden_frame_byte_for_byte`：用 M0 金标准 `session-20261010-c3-hook` 里
  `port=7200 && dir=s2c && ident=100` 的**原始线缆帧**（seq 66，`recog=0x7c303998`、`param=0xFFDB`、
  `series=1`、尾 GBK「唯一客服QQ：79311185 唯一担保QQ：79311185」）逐字节重建；
- `kick_user_msg_is_oracle_text_in_gb2312`：账号级文案 = oracle 字面量的 GB2312 字节；
- `account_kick_sends_sysmessage_then_soft_closes`：旧连接立即收 `SM_SYSMESSAGE`（ident 100、`Recog`=旧
  `ActorId`、`Param=make_word(0xFF,0x38)`、`Series=1`、尾=文案 GBK），**同一 tick 后段**才 `KickUser` +
  离开世界（oracle 是下一 tick——见 §4.1 O-1）；
- `duplicate_login_race_has_both_reachable_branches`：三支都可达——旧在世界（关新+踢旧）/
  旧已离场（放行）/ 旧仅在保存中（关新、**不踢旧**）。

## 4. 登记（不静默）

1. **`InSaveRcdList` 生产侧未接线**：`FrontEngine::begin_save/end_save` 只有单测在用；存档回写属 **S2b-3**
   （`openmir2-m2-session-lifecycle` 之外）。本片按 oracle 的**判据**原样实现（`in_save` 参与准入门、并有
   单测覆盖），但真机上 Rust 的「保存中」窗口目前恒为空 ⇒ 竞态窗口比 oracle 短（oracle 有
   `SaveHumanRcd` 的回写延迟）。**登记，不臆造延时**。
2. **真机夹具复跑未做（前置未满足）**：`brief` §8.3 要求「用夹具脚本再跑一轮」。本轮
   `E:/tmp/openmir2-watch/lane-status.log`（末条 18:12:56）显示 **`m1load` 车道在跑**，且实机端口
   `5000/5500/5600/5700/6000/7000/7100/7200` 被**另一条线的 C# 栈**（`GameSrv.exe`(39732)/`LoginGate.exe`(47128)/
   `GameGate.exe`(48920)/`SelGate.exe`(25556)/`DBSrv.exe`(41232)/`LoginSrv.exe`(37484)）独占 ⇒
   **不起栈、不占端口**（照 `brief` §0c 的纪律）。Rust 侧真机对齐证据**待端口窗口**。
   （2026-10-12 04:xx 复查：窗口已空，仅共享 MySQL `3306`；本片为**纯文档收口片**，仍未复跑，
   此项仍由独立真机片承接。）
3. **`payMode != 0`（账号付费过期文案）**：oracle `DelSession` 因 `sessInfo = null` **恒传 0** ⇒ 只实现
   `sKickUserMsg` 一支（1:1）；`ISM_ACCOUNTEXPIRED`/`SS_KICKUSER` 仍在 `ids.rs` 的「登记不做」清单。
