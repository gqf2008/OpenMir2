### 3.1 帧 52 `WAbil` 的逐字段 diff（**新发现，请 owner 裁决**）

`tools/m2-acceptance/evidence/m2svr-run-20261012-2/s2c/field-diff-52.txt`（解码口径 = `Ability.cs` 的
`SerializeLayout.Sequential` 22 字段，与 Rust `record::decode_ability`/`encode_ability` 同序）：

```
field                golden       rust
dc                      257          0  <-- DIFF
hp                       15         19  <-- DIFF
max_hp                   19          0  <-- DIFF
max_mp                   15          0  <-- DIFF
weight                   14          0  <-- DIFF
（其余 17 字段全等：ac/mac/mc/sc/mp/max_exp/max_weight/max_wear_weight/max_hand_weight…）
```

- Rust 值来自 `ability::recalc_abilitys`（m3bag 交付、已独立审查）：`hp = inputs.cur_hp = record.Abil.HP`、
  `max_hp = record.Abil.MaxHP + 装具 add.hp`、`weight = RecalcBagWeight(背包)`、`dc = record.Abil.DC + 装具 add.dc`。
- 观察者 `aaa` 的角色库 `characters_ablity`：`HP=19, MaxHP=19, MAxMP=15, DC=0, Weight=0`，背包只有 1 条**空槽**行。
  ⇒ Rust 的 `hp=19` 与库一致；**但 `max_hp=0`/`max_mp=0` 与库 `MaxHP=19/MAxMP=15` 不符**——这是 Rust 侧要查的口径
  （记录 `Abil.MaxHP` 没到 `recalc` 的 `abil.max_hp`？抑或 `record.rs` 读档链某处丢字段）。
- `dc=257`(=0x0101) 与 `weight=14`：金标准角色 **不是裸装**（虽 `50` 的 feature 显示 dress/weapon=0，说明差异来自
  **不可见槽**——戒指/项链/手镯一类），而 `aaa` 无装 ⇒ 这两项很可能是**夹具差**，非代码差。
- **处置**：本片**不改** `ability.rs`/`record.rs`（属 m3bag 写集，且需先钉「库 MaxHP 是否应到达 record.Abil.MaxHP」），
  以 comment 交 owner 裁决；**不自行登记白名单**（§6.0-3：白名单条目要 owner 签字）。
