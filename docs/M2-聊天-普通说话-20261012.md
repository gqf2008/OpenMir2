  ⇒ 只加驱动阶段而不接服务端回声，截图里不会出现本角色的文本。本片把**服务端回声**与**驱动阶段**一起交。

## 1. 结论（一句话）

`CM_SAY(3030)` 的**普通说话**（非 `@` 命令、非 `/` 私聊、非 `!` 频道）在 GameSvr 侧落
`SendRefMsg(RM_HEAR, FColor, BColor, "ChrName:sMsg")` ⇒ 对**以说话者为中心 ±`SendRefMsgRange`(12) 格内、
同图、`Race==Play && !Ghost` 的 actor（含自己）**各发一条
`SM_HEAR(40)`：12B 头 `Recog=说话者 ActorId`、`Param=MakeWord(FColor,BColor)`、`Tag=0`、`Series=1`，
尾 = `EncodeString("ChrName:sMsg")`。客户端收到自己的那条回声即渲染出本角色说的话。

## 3. 改动（一片一逻辑：`bins/game-svr/**` + `tools/client/**`，不碰 `crates/**`）

- **新增 `bins/game-svr/src/chat.rs`（进 `lib.rs`，纯函数 + 单测）**
  - `is_plain_say(line)`：`!line.is_empty() && !starts_with('@'|'/'|'!')`（= 会落到 `base.ProcessSayMsg` 的那一支）；
  - `hear_text(chr_name, say)`：`ChrName + ':' + sMsg`（GBK 字节拼接，不在本层转 UTF-8）；
  - `hear_targets(world, speaker_id, range)`：`ObMode||FixedHideMode ⇒ [自己]`；否则 ±range 方格内、
    同 `map_id`、`Race==Play && !Ghost` 的 actor（**含自己**），按 `ActorId` 升序返回
    （本项目要求顺序显式化；oracle 是格子扫描序，集合相同、帧字节相同）；
  - `SEND_REF_MSG_RANGE = 12`（现网与 oracle 缺省一致）。
- **`bins/game-svr/src/smframe.rs`**：新增 `sm_hear(actor_id, f_color, b_color, msg)` —— 12B 头 + `EDCode.EncodeString` 尾。
- **`bins/game-svr/src/config.rs`**：`[Setup] HearMsgFColor/HearMsgBColor` 解析（缺省 `0x00`/`0xFF`，含单测）。
- **`bins/game-svr/src/main.rs`**
  - `GateEvent::Command` 带 `chr_name`（在网关连接自己的 `UserList` 上解出的说话者，见 §2 第 8 行）；
  - `sim_loop`：`cmd.ident == CM_SAY` ⇒ `handle_say(...)` 组 `SM_HEAR`，对 `hear_targets` 逐个
    按其 `[GateIdx, Socket]` 经 `route_to_gate` 发 `SimToGate::SendFrame`；
  - `gbk_encode`（回帧尾与 oracle 的 GB2312 字节一致）；
  - 进程级用例 `say_broadcasts_hear_to_self_and_near_players_only`。
- **`tools/client/mir_flow.ps1`**：新增 `talk` 阶段（`-SkipTalk` / `-TalkText` / `-TalkBox` / `-TalkShot`），
  在 `ingame` 之后用回车开聊天框 → 注入文本 → 回车发送 → 截 `m2-03-talk.png`。
- **未改** `crates/**`、`src/**`（C# oracle）、`MirClient`、表结构/脚本/数据格式、现网配置。
