## 1. 本机环境适配（card_window 在本机首次真跑，三处阻塞与修法）

本机此前无任何 `card_window.py` 真跑记录（2026-10-24 rehearsal 只做 dry-run；全机搜不到历史 `card-window.json`）。三处阻塞全部在 **profile / 包装脚本层**修掉（`E:/tmp/window/run1/profile-alt-ignore14.json`、`profile-windowmagic-ignore14.json`、`start-csharp-warmup.ps1`、`start-rust-warmup.ps1`），**工具与场景一行未改**：

1. **restore 的 `bash` 解析到 WSL stub**：`CreateProcess` 找 `bash` 时 System32 先于 PATH，命中 `C:\Windows\System32\bash.exe`（WSL，未装发行版，rc=1）。修法：profile 两侧 restore 改 Git bash 绝对路径 `C:/Program Files/Git/usr/bin/bash.exe`。
2. **stack 步死锁（孙进程继承 stdout 管道）**：`start-csharp3.ps1` 以 `Start-Process -RedirectStandardOutput` 派生服务端，孙进程继承 python↔powershell 的 stdout 管道写端；`subprocess.run(timeout=600)` 超时 kill 后 `communicate()` 等 EOF 永不到来。实测 stack 步 13 分钟无返回、无存活子进程；最小复现脚本（`E:/tmp/window/run1/pipe_repro.py`）20s 后仍挂。修法：栈命令换 WMI `Invoke-CimMethod Win32_Process Create` 派生（父进程是 WmiPrvSE，无句柄继承）。
3. **GameGate 幽灵会话吃掉 enter-world**：`wait_ready` 对 17200 的连接探针（3ms 开关）在 GameGate 占住 user 会话槽 `SessionId:[0]`；596ms 后 probe 的真实连接复用同一槽被丢，GameSrv 只记「新用户链接」不应答 ⇒ `no SM_LOGON(50)`。两次实测（13:00 未暖、13:09 暖 45s 后）同型失败；对照：手动起栈暖 60s 后直接 probe ⇒ `exit=0 frames=29`（与 10-23 `w24-csharp-login` 基线一致）。修法：profile `ready_ports` 去掉 GameGate（17200/17600），GameGate 就绪改由 stack 包装脚本兜底（等全就绪端口监听 + 暖 45s；缺端口非零退出 fail-closed）。
   - 附：probe 密码用文档已载测试账号同名额 `CONFORMANCE_PASSWORD=winplay0`（`docs/conformance-batch1-login-20261023.md`）。

> **待办建议（另卡，本轮不动工具）**：① 三处阻塞在任何 Windows 机器首跑都会踩，建议把「绝对路径 bash + WMI 派生 + ready_ports 不含网关端口」落进内置 profile/preflight 自查；② spell_cast 的控制帧混入（见 §2 表 18 行）需要 probe/compare 层滤 `frame_class=server_ack_time`。

## 3. diff 明细与对应 R 卡

1. **`characters_ablity.Weight` C#=14 vs Rust=0**（key 6228；出现于 `login_only` / `dice_chain_auto` / `gm_batch` 三个有存档场景，可稳定复现）——coverage 表 `openmir2-login-numeric-gaps`（§2）明列「首登 52 Weight/MaxExp」数值列差类；归该 R 卡窗口证据（**未修**，按红线只记录）。
2. **`npc_click` 帧序差异**（rust 多 `[41 SM_FEATURECHANGED, 643 SM_MERCHANTSAY]` 尾巴 + index 29 错位）——归 `openmir2-click-path-bag-writeback`（npc_click 主卡）与 `openmir2-npc-display-table`；41/643 的组帧次序属 R 级时序证据。
3. **ident=100 时间文本 3 字节差**（gm_time/gm_batch）——环境噪声类（墙钟），非实现差异；需**另开卡**登记比较口径（如掩时分位 / 规则表 ignore+值断言），涉 GM 时间类窗口判据。
4. **`spell_cast` 控制帧混入**——工具缺口（probe 把 `server_ack_time` 记成帧），需另卡修 probe/compare 过滤；spell_cast 本身两侧都跑完，过滤后可直接重跑出 verdict。
5. **`dice_chain` actor 跨会话失效**——工具/场景机制缺口：`--var` 两侧同值 & 值只在会话内有效；已有 `dice_chain_auto` 覆盖（本轮帧流全同）。建议 dice_chain 改走 auto 或把链内 actor 发现并入会话（另卡）。
6. **`bag_equip`/`eat_item` 背包夹具 vs 基线表结构**——`openmir2-window-inventory-fixture`（已合入但 acceptance④ 未跑）的缺口实锤：夹具预期的 `characters_bagitem.ChrName` 列在本基线库不存在。修法＝夹具按实际列名适配或基线补列（另卡，改前先对 C# oracle 实表 `DESCRIBE`）。
7. 其余 UNDECIDABLE（pickup/move_walk/merchant/king×2/npc_script_chain/equip_struck/upgrade_retrieve）＝**部署前置缺口**（地物/摆位/语境/库存夹具），不是两侧实现分歧；按 §7.4 逐项补前置后即可真跑。
