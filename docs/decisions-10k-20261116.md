## 项目内决策（Leader）

- **P1 是唯一无争议的第一步**：收益不依赖任何未决项；先拿到实测降幅，再谈 P2 的 N/T。
- **先做 `lib.rs` 模块抽取（P1-5）再并行**——92k 行单文件会让 P2 的写集串行。
- 地图组划分：先连通性 + 静态均衡，热点再告警。
- 跨片全局服务：行会/城堡/组队走协调器；交易与同图战斗留片内。
- N-shard 验收替代：可重放 + 帧完整性 + 场景测试（写进 review 的 tier/tier_why）。
