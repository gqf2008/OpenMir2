## 5. 纪律与红线（接手必须遵守）

1. **walgit 流程**：一卡一 owner；交付 = `patch`（`--base/--head`）+ `status: needs-review`；**不 merge、不自签 review**（review 必须不同 principal）。
2. **tier 分级**（owner 2026-10-13 经 jev 决策）：**L 级**（纯逻辑/重构/文档/夹具/常量）= 审查者自证逐行或语义等价 + ≥1 条抽样冒烟即可放行；**R 级**（RNG 抽数序列 / 时序 / 持久化落库 / 战斗数值）= **保留真机全量对拍**，**不许用"语义等价"盖掉**；判不准按 R。review 里必须带 `tier` + `tier_why`。
3. **四门禁**（合并树、`CARGO_TARGET_DIR` 放数据卷、别落检出内）：`cargo fmt --all -- --check`、`cargo clippy --workspace --all-targets -- -D warnings`、`cargo test --workspace`、`cargo run -p msgcodegen -- --check`（604 常量）。外加**证据四件套**（命令 + 输出 + 路径 + hash；`SHA256SUMS` 按 LF/git blob 口径，`python -I tools/evidence-hash/verify_sha256sums.py verify <清单>` 自检）。
4. **写集纪律**：同文件/同模块同时只有一个 owner；跨系统并行可以，同系统内部串行。
5. **身份**：一个 worktree 一个身份（`<git-dir>/walgit/identity`）。**主检出身份 = `openmir2-reviewer-5`**（也是 `rev` 车道身份）；本轮我新注册了 `openmir2-worker-20`（m3hp 车道）与 `openmir2-worker-21`（m3pt 车道），其密钥在各自 worktree 的 `walgit/keys/` 下。**禁止共用密钥/代签**；`svc-*` 前缀不计入人类批准。
6. **窗口纪律**：起停栈**同一 `-LogDir`**；收窗后实拍十端口；开窗前确认没有别的车道在编译（`lanes-pause` 新版会连在跑实例一起停）；P99 类判据必须空闲窗口。
7. **内容冻结**：`Envir` 脚本/地图、三库表结构与基准内容不随手改（对拍锚点）；测试状态（角色/物品/行会）可随意重置，但破坏性操作前先快照。

## 7. 已知坑（本轮实战踩到的，别再踩）

1. **`pi -p` 的 stdout 是整段缓冲**：长 burst 里 `agent-<tag>.log` 恒不动 ⇒ 别拿它当心跳。存活判据 = pi 会话 jsonl + 活子进程（`supervise.sh` 的 `lane_age_min()` 已实现）。**此前这条错判据导致一晚上 21 次误杀在跑的车道。**
2. **注释不能停用车道**：`supervise.sh` 用 `grep '|worker|'` 抽行，**不看行首 `#`** ⇒ 停用必须**整行移出** `lanes.conf`（项目注释里早就写了，我违反过）。
3. **改"唯一副本"文件（brief / lanes.conf / 脚本）前先备份 + 写入前判空**：我用 `[IO.File]::WriteAllText($p, $null)` 把 m2svr/m3cs 的 brief 清成 323B（教训：PowerShell `-replace` 三元素会失败、`$null` 会覆盖文件）；恢复手段 = 从**该车道的 pi 会话 jsonl** 里抠回（车道每 burst 会 Read brief；Read 输出有 ~50KB 上限）。
4. **改正在被长活循环执行的脚本要原子替换**（写 `.tmp` + `Move-Item -Force`），否则 tick 读到半成品：`line 50: $'\277\207…': command not found`。
5. **杀进程只按 pid 精确匹配**：用命令行模糊匹配（`CommandLine -match 'supervise-loop'`）会**把调用方自己一起杀**（实测两次）。MSYS 的 `$$` 也不是 Windows pid。一条"循环"是嵌套 bash 进程树（3 个进程），按数量"去重"会把循环连根拔。
6. **卡执行/监督任务（`schtasks`）与在跑进程要一起停**：只 disable 任务，已在跑的车道会继续干到 burst 结束。
