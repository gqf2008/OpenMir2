# 附：MG-45 归属补充（2026-11-21，`a2` 复核退回后）

> 退回意见：`cast_big_explosion_spell` 是 23/33/47 共用函数，`power +1` 的 33 支红只披露了范围、
> 未证明"33 专属"。本附节补两层：(一) 把"power 面是三叶共用路径"写成结论；(二) 另做一颗
> **33 专属**的 range 选支变异，做到 33 红、23/47 绿。被验 head：`9cf112887a8c0ef85abb4ca77a9d34df2720e3ae`。

## 7. (一) power 面：**三叶共用路径**（结论，含代码位置）

- `crates/world-bevy/src/world.rs` 的 **`cast_big_explosion_spell`** 在**函数入口**统一算
  `power = power_magic_attack(...)`，随后在逐目标循环里把同一个 `power` 写进每个 `PendingMagStruck`。
- 宿主在 `bins/game-svr/src/lib.rs` 里用**单臂** `23 | 33 | 47 =>` 调它；三号之间**只有 `range` 不同**：
  `if req.magic_id == 33 { snow_wind_range } else { fire_boom_rage }`。
- ⇒ **现有 `power +1` 变异必然同时命中 23/33/47**，它只能作「**三叶共用路径牙**」，
  不能证明 33 专属。原 §3/§5 的 33 红**保留**为共用路径覆盖证据（不删）。

## 8. (二) 33 专属 range 选支变异（+3，半径 1→4）

- **变异点（产品侧）**：`bins/game-svr/src/lib.rs` 的 `23 | 33 | 47 =>` 臂里，
  `if req.magic_id == 33 { snow_wind_range }` → **`snow_wind_range + 3`**（23/47 仍走 `fire_boom_rage`，不受影响）。
- **最小可观测幅度 = +3（1→4）的下界推导**：`crates/world-bevy/src/world.rs` 的
  **`mag_objects_in_range_impl`** 是**方框、闭区间**（`x ∈ [n_x-range, n_x+range]`、`y ∈ [n_y-range, n_y+range]`），
  遍历序 x→y→`obj_list`，过滤 `actor_object` 且 `!death && !ghost`。夹具中心 = 目标格 `(101,100)`，
  最近的其他 actor 是 `obs_in(105,100)`（`dx=4`）⇒ **覆盖它需 `range ≥ 4`**，基线 `snow_wind_range = 1`
  ⇒ **+3 即推导出的最小可观测点**（`+1/+2` 覆盖不到任何新 actor，预期必绿，故未再耗构建去跑）。
- **二次门（"能否命中 ≠ 能否进枚举"）**：进箱后还要过 `combat::is_proper_target_grouped`（玩家目标还要
  `is_protect_target` 为真）。本次 +3 实测**已穿透**二次门（见下），故不需要走"过滤门挡住"分支。
