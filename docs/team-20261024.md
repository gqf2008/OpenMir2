## 规则

1. **一 worktree = 一身份 = 一把 Ed25519 私钥**。worktree 一律由 Leader 建在 `.worktrees/<角色>/`（仓库内、已在 .gitignore）；**绝不删除成员 worktree**（身份在 `.git/worktrees/<name>/walgit/`）。密钥备份：`E:/wt-backup-20261024/team-20261024/`。
2. **一卡一 owner**：卡片线程的签名 `status` 是唯一认领账本；Leader 建卡即钉 owner，防抢卡。
3. **审查与作者必须不同 principal**；Leader 复审审查结果后才合并（approve ⇒ `merge --no-ff` + 完整门禁 + push + `merge_result`；L 卡 closed，R 卡 in-progress 待窗口）。
4. 日常 fetch/push 只对 `walgit`（主源）；GitHub `origin` 仅人工同步。
5. 每张卡必须有：goal / write_set / oracle 行号或证据来源 / acceptance（含牙）/ forbidden / tier；交付 = 先签 status → commit → push → `patch` → `needs-review`。
6. Leader 合并后清理：卡片分支（本地+远端）删除；worktree 保留。
7. 分级：R = 触 RNG/时序/持久化/战斗数值，需真机窗口证据；L = 等价 + 抽样冒烟即可。判不准按 R。
