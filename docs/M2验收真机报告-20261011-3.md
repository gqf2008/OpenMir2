## 2. B-1：BOM 收口 + 真机端到端验证

**缺陷**（reviewer-2 `b49897e8`）：现网 `Server.conf` 首字节 UTF-8 BOM；`read_to_string` 保留 `U+FEFF`，
`trim` 不剥 ⇒ 首行 `[DataBase]` 头丢失 ⇒ `ConnctionString` 缺键 ⇒ 回落 `database=mir2`（现网不存在该库）
⇒ `stditems` 恒空 ⇒ 带装备角色的 50/41 与 oracle 偏离（裸装夹具/真机号掩盖）。

**修法**（照 C# `StreamReader` 的 BOM 探测语义）：`config::load` **只在文件首**剥一个 `U+FEFF`——
`let text = raw.strip_prefix('\u{feff}').unwrap_or(&raw);`（不是每行、不是循环）。
`crates/envir::GameSvrConf::load` 读同文件其它段，已由 `crates/envir/src/text.rs` 覆盖，不在本片写集。

  入库摘录 = `evidence/real-run-20261011-3/game-svr-keylines.txt`（sha256 `81100c6c…`）。
