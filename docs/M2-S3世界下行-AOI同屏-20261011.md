## 1. 结论（一句话）

把**世界 tick 的 AOI 结果**（观察者实体 `VisibleActors` 里本轮 `VisibleFlag::Show` 的对象）翻成
oracle 口径的 `SM_TURN`(10) + 紧随的 `SM_FEATURECHANGED`(41)，按该观察者的 `[GateIdx, Socket]`
路由回**它自己那条**网关线并经 `SimToGate::SendFrame` 上路——这就是真机 ② 里 `see-others` 上不来的
那个缺口（世界侧 AOI/同屏同步）。**不进 `crates/world`**：展示层字段（`Dir/Light/Feature/…`）
由 `bins/game-svr` 在进世界时登记进 `DisplayTable`（`ActorId -> ActorDisplay`）。

## 3. 改动（一片一逻辑：`bins/game-svr/**`，不碰 `crates/**`）

- **新增 `bins/game-svr/src/downlink.rs`（进 `lib.rs`，纯编码/纯函数）**
  - `ActorDisplay`：`dir/light/feature/feature_ex/status/name_color/show_name`（展示层字段）；
  - `DisplayTable`：`ActorId -> ActorDisplay`（`Vec`，不靠 `HashMap` 迭代序）；
  - `my_light(level, &[(Index,Dura)], catalog)`：`GetMyLight()` 的 1:1（含 `EFFECTIVE_HIGHLEVEL = 50` 分支）；
  - `turn_pair(target, x, y, &ActorDisplay) -> Vec<Vec<u8>>`：产出 `SM_TURN` + `SM_FEATURECHANGED` 两帧；
  - 单测 `turn_pair_rebuilds_golden_sm_turn_and_featurechanged`：**从 M0 金标准的真字节回读**
    （x/y/dir/light 取 `SM_TURN` 头；`feature/feature_ex` 取 `SM_FEATURECHANGED` 头；`CharDesc`/`ShowName`
    取 `SM_TURN` 尾解码），断言两帧**逐字节**重建金标准 seq 30(`10`) + seq 31(`41`)；
  - 单测 `my_light_follows_get_my_light`：等级分支 / `Dura==0` 不计 / 取最大值 / `GetStdItem==null` 不计。
- **`bins/game-svr/src/main.rs`**
  - `sim_loop` 持有 `displays: downlink::DisplayTable`；
  - 进世界成功（`enter::apply` 之后）：用记录 `Abil.Level` + `hum_items`(Dress..Charm) + `stditems` 目录算
    `my_light`，把 `inputs.logon_body_wl` 的 `feature/status`、`inputs.feature` 的 `feature_ex`、
    `inputs.dir`、`GetShowName()`（`enter::show_name` + GBK，与帧 42 同源）、`PLAY_NAME_COLOR` 登记进表；
  - **每轮 `world.tick()` 之后** `drain_aoi_downlink(...)`：按 `SessionRegistry` 顺序 × `VisibleActors`
    列表顺序，对每个 `VisibleFlag::Show` 且 `!= 自身` 的目标产 `turn_pair`，经 `route_to_gate(gate_idx, socket)`
    发 `SimToGate::SendFrame`（帧在 `apply_sim_cmd_async` 变成 `GM_DATA` 上路）；
  - 断线（`GateEvent::Closed`）时把该 `ActorId` 从展示表摘除（防槽位回收后旧展示值残留）；
  - 单元/进程级用例 `aoi_show_emits_turn_pair_routed_by_gate`。
- **未改** `crates/**`（含 `crates/world`）、`src/**`（C# oracle）、`MirClient`、表结构/脚本/数据格式、现网配置。
